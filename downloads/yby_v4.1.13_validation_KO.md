# YBY V4.1.13 검증 결과

검증일: 2026-10-20 (한국시간). 기준 소스: V4.1.12.

## 자동 검증

- Python 서버 **241개 통과** (113.477초, 실패/스킵 없음). 기존 231개 + 신규 10개.
- 신규 항목: 명시적 배부 상태 저장/조회, 회수완료의 실제 날짜 필수 및 미래 날짜 차단, 이전 API에서 기존 상태 보존, 과거 자료의 표시 추정과 원본 불변, 확인완료 자료의 등록 엑셀 제외/수정 후 재포함, 최초 등록일/현재 상태/삭제·이관 분리, 이력 조회만 가진 사용자의 현재 지점 자료 조회와 변경 차단, 대시보드 유류대 수량 지점 제한/상세 권한, 등록 전용 권한으로 확인 후 리스트 관리, 4개 초과 바로가기 저장.
- 마지막 회수일 검사 보완 후 관련 Python **65개 재검증 통과** (44.529초). 이전 클라이언트 형식으로 회수완료 상태의 날짜를 미래로 바꿔도 차단됨을 포함합니다. 이 65개는 위 테스트의 재실행으로 총합에 중복 합산하지 않습니다.
- Node 이력·집계 **12개 통과**. 구별되는 자동 테스트 합계 **253개**.

- 읽기 전용 한글 원본 경로 → 사용자 실행 폴더 설치/시작/로그인/업무 저장, 중복 실행 시 같은 PID, 반복 설치 시 자료 유지 확인.

## 배포 파일 확인과 한계

최종 ZIP CRC/전체 파일별 SHA-256/추출본 bootstrap 무결성, Python 3.11 문법 및 JavaScript 문법, PowerShell BOM과 이전 버전 파일 바이트 동일을 검사합니다. ZIP은 명시된 파일 목록으로만 만들며 운영 DB·개인키·진단 로그·회사 첨부문서·시험 수신 자료를 넣지 않습니다. 다운로드 게시 후 실제 URL로 다시 받아 SHA-256와 ZIP 무결성을 확인합니다.

회사 Windows/Edge/WebView2, 실제 인증서 등록/회사 방화벽 정책, 실제 Oracle DB는 이 클라우드에서 실행하지 않았습니다. 회사 PC에서 최종 실행 확인이 필요합니다. Oracle 접속·수집 구현은 담당자 자료 대기 상태로 유지합니다.
