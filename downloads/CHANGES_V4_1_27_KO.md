# YBY V4.1.27 — V4.1.26 기반 개선

기준: `yby_v4.1.26_full.zip` (SHA-256 `ea22d47d1773affc79554c9b1876f509dd8f95976633f8149ea226e9fbc4700a`). 기존 계정·비밀번호·업무 이력·첨부와 인증서 연결 방식을 유지합니다. 회사 운영 DB는 이 패키지에 포함하지 않습니다.

## 1. 계정별 메뉴와 고정 선택

- 상단 **메뉴**에 마우스를 올리거나 클릭하거나 `Alt+M`을 누르면 업무 메뉴가 열립니다. 각 분류에 마우스를 올리거나 키보드로 이동하면 하위 메뉴가 나옵니다.
- 열 때마다 로그인 계정의 현재 서버 권한으로 하위 메뉴와 분류 표시를 다시 계산합니다. 최고관리자 전용 메뉴의 접근 검사는 유지합니다.
- **메뉴 보임 (좌측 고정)**을 체크하면 좌측에 고정하고 본문 폭을 조절합니다. 체크 해제 시 자동 숨김 방식이며 업무 선택 후 메뉴가 닫힙니다. 표시 설정은 계정별로 서버에 보존합니다.
- 6개 분류에 작은 선형 아이콘을 추가했습니다. 좁은 화면에서도 본문을 덮지 않도록 고정 메뉴 폭을 조절합니다.

## 2. 사용별 보유·사용·특이사항 상세

- 대시보드 버튼과 창 제목을 **사용별 보유·사용·특이사항 상세**로 변경했습니다.
- 사용자별 / 지점별 전환, 지점 선택, 이름·지점 검색, 8개 항목씩 페이지 조회를 제공합니다.
- 묶은 막대 / 누적 막대 / 점·연결선 그래프를 선택할 수 있습니다. 연결선은 항목 비교이며 시간 추세가 아닙니다.
- 넓은 창과 큰 그래프, 기울인 축 이름, 전체 이름 툴팁, 차트별 합계·최다 비중·특이사항 안내를 제공합니다. 분석 합계는 검색 결과 전체, 차트는 현재 페이지 기준입니다.
- 서버에서 허용한 업무 영역·지점 자료만 사용합니다. 권한 없는 영역은 차트에서 제외합니다.

## 3. 사고·사용 관리 상태 색상

정상은 기본 녹색 계열, 분실은 적색, 파손은 주황, 장기사용은 황색, 교체는 청색, 사용중지는 보라, 기타는 청록 계열로 표시합니다. 선택 상자·관리 입력 영역·현황 및 이력 행에 상태명을 함께 표시합니다. **기타**도 필수 접수·조치 내용을 기록하며 신규 불출을 제한합니다. 정상 복귀 이후에도 기존 사고 이력은 보존합니다.

## 4. 후속점검 권한과 과거 기록 연결

- 저장 기록의 **작성자 및 최고관리자**가 후속점검을 열고 저장하도록 서버에서 확인합니다. 다른 작성자의 후속점검 시도는 차단합니다.
- 과거 형식의 숫자 ID 및 신청자 식별 정보가 빠진 대상은 같은 지점·원본 종류에서 유일하게 식별되는 원문만 연결합니다. 중복 시 임의 연결하지 않습니다.
- 원문이 없는 경우 권한 오류 대신 저장 당시 대조표·작성자·명세·결과를 읽을 수 있게 표시합니다. 현재 원문 없는 기록을 새 원문 대조 완료로 저장하지 않습니다.
- 원문이 변경된 건은 재조회가 필요하며 후속 기록은 이전 기록을 참조하여 추가 저장합니다. 점검 완료로 원래 반납·정산·결재 상태를 변경하지 않습니다.

## 5. 보고서 그림·표·서식 편집

- 보고서 본문에 굵게·기울임·밑줄, 글꼴 3종, 크기 6종, 색상, 정렬, 글머리, 표, 그림, 실행 취소·다시 실행을 제공합니다. **일반 텍스트 편집**도 선택할 수 있습니다.
- 그림은 **그림 넣기**에서 선택합니다. 본문과 첨부 목록에 함께 추가되며 일반 첨부를 포함해 최대 5개, 파일당 20MB입니다. PNG/JPEG/GIF/WebP를 지원합니다.
- 표는 **표 넣기**에서 행·열 수를 지정하고 셀에서 내용을 편집합니다.
- 미리보기만으로 업로드·상신하지 않습니다. 최종 확인 시 첨부 업로드 후 서식과 함께 저장합니다. 저장된 문서 보기에서도 그림·표·서식을 유지합니다.
- 서버는 제한된 문서 구조만 저장합니다. 외부 이미지 주소·스크립트·임의 HTML/CSS는 허용하지 않습니다. 본문 그림은 해당 기안의 소유자·지점·용도가 맞는 첨부여야 합니다. 예전 일반 텍스트 보고서와 정산 원본 복사 연결을 유지합니다.
- 일반 텍스트 전환 시 본문 서식·표·그림이 해제된다는 확인창을 제공합니다. 첨부파일 목록은 유지합니다.

## 6. 작성 화면의 우측 공간

보고서와 민원 화면의 안내 아래에 차분한 선형 풍경, 작성·접수 흐름, 제목·본문 글자 수·첨부 개수 표시와 개인정보 안내를 배치했습니다. 기존 위로 문구 자동 전환은 유지합니다.

## 7. 항상 보이는 상단 카드 매수

시스템 제목 옆에 **총보유매수 / 사용가능 / 대여중 / 기타**를 표시합니다. 로그인과 업무 처리 후, 화면 활성 중에는 약 5초마다 갱신합니다.

- 종료 카드 제외. 최고관리자는 전체, 일반 계정은 담당 지점 합계입니다.
- 사용가능: 정상 관리 상태·미만료·보관 중 카드.
- 대여중: 현재 대여 중인 카드. 대여 중 사고가 접수된 카드도 대여중에 포함합니다.
- 기타: 사용제한·만료 등 위 두 항목 외의 카드. `사용가능 + 대여중 + 기타 = 총보유매수`입니다.
- 모든 활성 로그인 계정에 담당 범위의 **합계만** 제공하며, 상세 업무 자료의 조회·수정 권한을 확대하지 않습니다.

## 적용

1. 기존 서버의 전체 백업(DB·첨부·계정 복구 자료)과 인증서·설정을 별도로 보존합니다.
2. 패키지를 새 폴더에 풀고 기존 실행 방식의 안내를 따릅니다. Windows는 `RUN_WINDOWS.bat` 또는 기존 `RUN_LAN_WINDOWS.bat`, Linux는 기존 실행 안내를 사용합니다.
3. 신규 설치는 새 DB이므로 기존 운영 자료가 자동 포함되지는 않습니다. 기존 실행 폴더를 업데이트하거나 전체 백업을 새 서버에 복원한 뒤 검증해야 합니다.
4. 기존 DB 적용 전 전체 백업을 만들며 저장 형식 버전을 15로 기록합니다. 계정·기존 원문을 일괄 재작성하지 않습니다. 이전 프로그램으로 되돌릴 때는 업데이트 전 백업을 이용합니다.
5. 최고관리자와 실제 지점 계정으로 메뉴·첨부·기안·후속점검을 확인한 뒤 운영을 전환하세요. 회사 환경에서 확인하지 못한 항목은 검증자료를 참고하세요.
