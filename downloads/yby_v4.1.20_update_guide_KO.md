# YBY V4.1.20 업데이트 안내

## 사용정산이력대장에서도 쉽게 수기 정정

기존 정정 버튼은 표 오른쪽 ‘상태·관리’ 칸에 있었습니다. 표가 넓을 때 찾아가기 쉽도록 **사용정산이력대장의 표 바로 위**에도 정정 도구를 추가했습니다.

1. **엑셀 이관 건**에서 정정할 번호·지점·사용자·카드를 확인하여 선택합니다.
2. 옆의 **수기 정정**을 누릅니다.
3. 사용 여부·반납일·부서·반납/정산 진행상태를 수정합니다.
4. 정정 사유와 **현재 로그인 계정의 비밀번호**를 입력해 저장합니다.

현재 조회된 엑셀 직접 이관 자료가 선택 목록에 나옵니다. 대상이 없다면 조회 조건을 초기화하거나 전체 이력으로 전환하세요. 표 오른쪽 행별 정정과 상세 보기 안의 정정 버튼도 유지했습니다. 최고관리자 또는 자기 지점 업무 수정 권한이 있는 담당자가 사용할 수 있습니다. 원본과 변경 전후 이력 보존, 연결된 두 대장 동시 반영은 기존과 같습니다.

## 화면에 맞춤 / 가로 스크롤 선택

**두 이력대장 각각의 표 위 ‘표시 방식’**에서 선택합니다.

- **화면에 맞춤**: 기본값입니다. 모니터 폭 안에서 내용을 줄바꿈해 모든 열을 표시합니다. 좁은 화면에서는 열 이름이 붙은 세로형 기록으로 표시합니다.
- **가로 스크롤**: 열 너비를 유지하고 표 영역을 좌우로 스크롤합니다. 숫자·날짜를 더 넓게 보고 싶을 때 선택하세요.

같은 브라우저에서 계정별·대장별 표시 선택을 기억합니다. 이 선택은 화면 표시용이며 이력 데이터와 금액을 바꾸지 않습니다.

## 필터 줄 전체에 아래화살표 선택

일련번호 한 칸만의 기능이 아닙니다. **사용정산이력대장 15개 열, 불출반납이력대장 18개 열의 필터 줄 전체**에 아래화살표를 추가했습니다.

- 검색칸 오른쪽 **아래화살표**를 누르면 해당 열에 존재하는 값을 선택할 수 있습니다.
- **전체**를 선택하면 그 열의 선택 조건을 해제합니다. 빈 값은 **(빈값)**으로 선택합니다.
- 직접 글자를 입력하는 검색과 번호 범위 검색도 그대로 사용할 수 있습니다. 직접 입력하면 해당 열의 이전 선택 조건을 대체합니다.
- 화살표로 선택한 값은 **정확히 일치하는 값**을 찾습니다. 예를 들어 ‘사용’ 선택 시 ‘미사용’이 함께 나오지 않습니다.
- 여러 열을 선택하면 조건을 함께 적용합니다. 상단 지점·기간 필터와도 함께 적용합니다.
- 선택 목록은 조회 권한과 업로드 한정 범위를 따릅니다. 다른 지점 비공개 자료를 선택 목록에 표시하지 않습니다.
- **조건 초기화**는 직접 입력·아래화살표 선택·업로드 한정 조건을 함께 초기화합니다. 현재 조건을 적용한 자료로 엑셀/PDF를 출력합니다.

## 엑셀 대량 업로드 선택 초기화

**외부자료 매칭 → 엑셀 대량 업로드** 영역에서 ‘미리보기 · 다시 검사’ 옆의 **선택 초기화**를 누르세요.

- 선택한 파일, 시트, 미리보기 표, 행 체크, 확인 체크와 임시 선택값을 비웁니다.
- 기본 소속 지점과 반영 방식은 유지하여 다음 파일을 준비하기 편하게 했습니다.
- **이미 저장된 이력과 중복 방지 기록은 삭제하지 않습니다.** 같은 원본을 다시 올리면 계속 중복 검사합니다.
- 검사 중 초기화한 경우, 늦게 도착한 검사 결과가 표에 다시 나타나지 않습니다. 다른 파일·검사 조건으로 바꾼 경우도 이전 검사 결과를 적용하지 않습니다.
- 실제 업로드 **저장 중에는 초기화를 잠시 막고** 완료 후 사용할 수 있습니다. 저장 중인지 알 수 있도록 안내합니다.
- 기존 매칭 영역의 ‘선택 초기화’는 문서 매칭 선택을 비우는 별도 버튼입니다. 파일을 비우려면 **엑셀 대량 업로드 영역의 버튼**을 사용하세요.

## 불출과 반납의 상태 메시지 구분

| 행 구분 | 표시 예시 | 의미 |
|---|---|---|
| 현재 YBY 불출 | 불출중 · 반납대기 | 실제 대여 중인 카드 |
| 엑셀 불출 기록, 반납 없음 | 불출 기록 · 반납대기 | 원본 기록에서 반납이 확인되지 않음. 현재 카드를 자동 불출한 것은 아님 |
| 엑셀 불출 기록, 반납 있음 | 불출완료 · 반납 확인 | 연결된 반납 기록 확인 |
| 엑셀 반납 기록 | 반납완료 · 사용정산 이관 | 금액 있는 원본 정산 이관 |
| 엑셀 반납 기록, 금액 없음 | 반납완료 · 정산금액 미기재 | 반납은 확인했고 금액은 미기재 |
| 엑셀 반납 기록, 0원 | 반납완료 · 금액 0원 | 원본에 0원이 명시됨 |
| 수기 정정한 반납 | 반납완료 · 정산확인중 / 정산완료 / 미사용 | 정정한 반납·정산 진행상태 |
| 반납일을 지운 기존 반납 | 반납기록 정정취소 | 원래 반납 기록을 감사 이력으로 보존 |

정산확인중·정산완료·미사용 등은 **반납 행에** 표시합니다. 불출 행에는 불출 완료 또는 반납대기를 표시하여 두 업무가 섞이지 않게 했습니다. 수기 정정한 건은 ‘수기정정’을 함께 표시합니다. 화면·열별 필터·엑셀/PDF에서 같은 상태 판정 함수를 사용합니다. 정산 이관과 수기 정정은 YBY 승인 기록을 자동으로 만들지 않습니다.

## 업데이트

1. 현재 프로그램에서 **전체백업**을 내려받아 보관합니다.
2. 서버 창에서 **Ctrl+C**로 종료합니다.
3. 새 ZIP을 **새 폴더에 모두 압축 해제**합니다.
4. 기존과 같은 Windows 계정으로 **RUN_LAN_WINDOWS.bat**를 실행합니다.
5. 로그인 후 두 대장의 표시 방식·필터 화살표와 사용정산이력대장 상단의 정정 도구를 확인하세요.

일반 업데이트에는 백업 복구를 실행하지 않습니다. 기존 자료·계정·첨부·인증서·사내망 설정을 보존합니다. 패키지에는 실제 회사 DB·업로드 Excel·암호·인증서 개인키를 포함하지 않았습니다.
