# YBY V4.1.18 검증 결과

검증일: 2026-10-20 (한국시간). 기준 V4.1.17, DB 스키마 8 유지.

## 실제 첨부 원본

별도 시험 서버에서 이전 **Book1.xlsx**를 HTTP로 미리보기·직접 반영했습니다. 실제 개인정보와 원본 Excel은 배포하지 않습니다.

- 제목 5행, 업무 6~9행을 읽어 정상 4행 확인.
- 사용정산이력 4건: 금액 있는 원본 1건 **225,000원**, 금액미기재 3건.
- 불출 이력 4건 + 실제 반납일이 있는 행의 반납 이력 3건. 마지막 행의 반납일은 만들어 넣지 않음.
- 사용자·부서·은행·카드 끝자리·신청/지급/예정/반납일·금액·참고 항목과 원본을 대조.
- 현재 카드·승인대기 정산·YBY 승인·새 수신 원문 중복 생성 0건.
- 재업로드 미리보기 중복 4행.

## 서버·계산 검사

- Python 전체 **321개 통과**, 실패/스킵 없음 (178.425초). 신규 직접 이관 검사 16개 포함.
- 최종 문구·참고값 정리 후 신규 **16개 재검사 통과** (9.826초). 반복 건수는 총계에 더하지 않음.
- Node 이력·통계 **26개 통과**, 실패/스킵 없음. 서로 다른 이관 행/실제 카드의 끝자리가 같아도 반납 연결이 섞이지 않는 검사 포함.
- 고유 자동검사 총 **347개**. 브라우저 시나리오와 반복 검사는 이 숫자에 중복 합산하지 않음.
- 동일 파일·이름 변경·행 순서 변경·파일 안 반복 행은 중복 제외. 내용 변경 충돌·지점 범위·무권한·익명·파일 변경·행 선택 오류 차단.
- 최대 **2,000행**의 실제 HTTP 반영: 사용정산이력 2,000건 / 불출 2,000건 / 반납 2,000건 / 합계 24,000,000원 / 재검사 중복 2,000행. 자동백업 시점을 강제로 도래시켜도 완료하는 검사 포함.
- 대량 쓰기 중 별도 DB 연결로 권한 조회·자동백업을 하면 읽기 대기가 생기는 문제를 확인했고, 두 작업을 쓰기 전에 처리하도록 수정.
- 저장 실패 시 전체 롤백. 일반 상태 저장으로 이관 기록 위조/수정 차단. 현재 대여 중 카드 상태 보존.
- V4.1.17 미처리 수신 자료의 명시적 이관, 기존 매칭 보존·잠금·재수신 방지. 실제 불출에 이미 사용한 원본의 이중 이관 차단.
- 0원과 금액 빈칸을 구분하고 승인자·승인일·수량·단가를 생성하지 않는 검사.
- 전체 백업·복구 후 대장과 중복 방지 등록부 보존.

## 실제 Chromium 브라우저

- Book1과 같은 제목 5행/업무 4행 구조에서 기본 ‘두 이력대장 직접 반영’ 확인.
- 행 미선택 안내, 확인창 취소 시 미저장, 확인란 미선택 상태의 구체적인 확인창, 저장 실패 시 입력 보존·재시도 확인.
- 실제 버튼으로 사용정산이력 4건/불출4·반납3 반영 → 대장으로 이동 → 다른 대장 버튼 연결.
- 일련번호·입력경로 열 위치, 목적 칸의 출처 중복 제거, 금액미기재·원본 미반납·합계225,000원, 결재 기록 없는 원본 상세 화면 확인.
- 실제 XLSX 다운로드 및 내부 XML의 새 열·금액 보존 확인. 금액 빈칸 3개가 0으로 바뀌지 않음.
- 이관 원본 상세 PDF 생성 후 텍스트 추출 확인.
- 1920/1440/1024/768/390/320px 업로드 작업영역의 가로 넘침 방지 확인. JavaScript 실행 오류 없음.
- 기존 수신함 방식도 별도 선택하여 수신/매칭/실제 카드 등록/불출/반납/정산 승인대기 흐름 회귀 확인.
- 기존 외부 매칭 수정·잠금, 통합 통계·다른 지점 차단, 하이패스 상태 색상·목록/출력 확인.
- 일반 업무 화면의 보고서 결재·저장 실패 입력 보존·전체백업 재인증/ZIP 다운로드·하이패스 등록·공지·개인 메모·메신저 저장·390px 모달 확인.

## 업데이트·실행 및 배포

- 별도 V4.1.17 실행 폴더에 기존 회사 자료를 모사한 DB·계정·재무 이력·수신/매칭/중복 기록·하이패스/유류대카드·변경 이력·첨부파일·인증서/설정을 준비하고 V4.1.18을 설치.
- 프로그램 교체 직후 DB 원본 해시 유지, 실제 서버 기동·로그인·기존 내역 및 수신 기록 보존 확인. 과거 자료 자동 변환 없음.
- 원본 패키지 해시 목록 검증·새 ZIP의 CRC/전체 MANIFEST 해시 검증. Windows PowerShell의 BOM 유지와 구문 관련 기존 자동검사 통과.
- 압축 파일에 실제 회사 Excel·업무 DB·개인정보·계정 암호·TLS 개인키를 포함하지 않음.

## 직접 확인하지 못한 범위

실제 회사 Windows/Edge/WebView2·인증서 저장소·방화벽/보안 정책 및 Oracle DB 직접 연결은 이 Linux 시험 환경에서 실행하지 못했습니다. 무오류를 보장하는 의미의 ‘완벽 검증’으로 표현하지 않습니다. 적용 전 전체백업을 보관하고 실제 회사 서버에서 로그인과 필요한 원본의 미리보기를 확인하세요.
