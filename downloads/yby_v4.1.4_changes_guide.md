# V4.1.4 로그인 전용 창 · 수동 실행 안내

2026-10-17. V4.1.3을 기준으로 사진처럼 간결한 로그인 화면과 필요할 때 실행하는 전용 창을 적용한 전체 패키지입니다.

## 사용 방식

- Windows 시작 메뉴에서 ‘YBY 로그인’을 실행하면 주소창 없는 로그인 전용 창이 열립니다.
- Windows 로그인 시 자동으로 실행하는 설정은 추가하지 않습니다. 바탕화면 바로가기를 새로 만들지 않고 현재 사용자의 시작 메뉴에 등록합니다.
- 로그인 화면은 YBY 이름, 아이디, 비밀번호, 로그인 버튼으로 구성했습니다. 기존 계정명과 비밀번호를 그대로 사용합니다. 최고관리자 아이디는 admin입니다.
- 아이디를 직접 입력하며 기존 계정명은 입력 제안에서 선택할 수 있습니다. 계정 목록을 갱신해도 입력하던 내용이 지워지지 않습니다.
- 성공하면 넓은 업무 창으로 크기 변경을 요청하고, 로그아웃하면 로그인 창 크기로 돌아갑니다. 일반 브라우저 접속에서는 창 크기를 변경하지 않습니다.
- 전용 창은 설치된 Microsoft Edge 또는 Google Chrome의 앱 모드를 사용합니다. 브라우저 정책으로 크기 변경이 제한되면 창의 최대화 버튼을 사용하세요.
- 로그인 오류는 입력란 아래에 표시하고 다시 입력할 수 있습니다. 로그인 처리 중에는 중복 요청을 막습니다. 최초 비밀번호 변경과 기존 권한 검사는 유지합니다.
- 프로그램에서 접속 PC의 비밀번호를 자동 저장하거나 자동 로그인하지 않습니다. 로그인 성공과 로그아웃 시 화면의 비밀번호 입력값을 비웁니다. 기존 서버의 관리자 비밀번호 보관 기능은 유지됩니다.
- 닫기 버튼은 접속 창을 닫습니다. 실행 중인 회사 서버는 계속 동작합니다.

## 서버 PC: 처음 한 번 적용

1. 기존 프로그램의 데이터 백업을 내려받아 회사 내부에 보관하고, 기존 서버 창에서 Ctrl+C로 종료하세요.
2. 새 ZIP을 별도 새 폴더에 전체 압축 해제하세요. `%LOCALAPPDATA%\YBY\app` 안에 압축을 풀지 마세요.
3. 원래 서버를 사용하던 동일 Windows 계정으로 RUN_LAN_WINDOWS.bat를 일반 실행하세요.
4. Windows PowerShell 사전 구문 검사와 READY V4.1.4를 확인하세요. 인증서/HTTPS 확인 후 로그인창이 열리고 시작 메뉴에 ‘YBY 로그인’이 등록됩니다.
5. 이후 서버가 실행 중이면 시작 메뉴에서 YBY를 검색하여 ‘YBY 로그인’을 실행하세요.

서버를 껐다가 다시 켰다면 먼저 RUN_LAN_WINDOWS.bat로 서버를 시작해야 합니다. 이번 변경은 사용자가 필요할 때 실행하는 로그인 창입니다. 서버 자동 기동이나 Windows 자동 로그인은 설정하지 않습니다.

기존 바탕화면의 YBY 바로가기(.lnk)는 직접 삭제해도 됩니다. 바로가기 삭제는 업무자료에 영향을 주지 않습니다. 프로그램의 data 폴더와 certificates 폴더는 유지하세요.

## 다른 업무 PC: 처음 한 번 적용

1. 서버 OPEN_LAN_CLIENT.bat에서 새 LAN_CLIENT.zip을 전달합니다.
2. 다른 PC에서 ZIP을 전체 압축 해제하고 INSTALL_AND_CONNECT.bat를 일반 실행합니다.
3. 기존 CA와 같으면 인증서 등록 질문이 반복되지 않으며, 현재 사용자의 시작 메뉴에 ‘YBY 로그인’이 등록됩니다. 최초 등록 시에는 서버 지문과 비교하여 같은 인증서인지 확인하세요.
4. 이후에는 시작 메뉴에서 ‘YBY 로그인’만 실행하면 됩니다. Python 설치는 필요 없습니다.

서버가 꺼져 있거나 연결되지 않으면 시작 메뉴 실행 시 안내창이 표시됩니다. 회사 서버가 실행 중인지 확인한 다음 다시 실행하세요. LAN_CLIENT의 CHECK_CONNECTION.bat도 사용할 수 있습니다. 집에서 회사 서버를 사용하려면 회사가 허용한 VPN/원격접속이 필요합니다.

## 저장 위치와 보존

- 회사 업무자료·계정·정산·첨부: 기존 `%LOCALAPPDATA%\YBY\app\data` 유지.
- 서버/CA 인증서·LAN 주소: 기존 설정 유지. DB 스키마 변경 없음.
- 시작 메뉴: 현재 사용자의 Programs\YBY\YBY 로그인.lnk. Windows 검색에서 YBY로 찾을 수 있습니다.
- 다른 PC의 공개 접속 도구: 기존 `%LOCALAPPDATA%\YBY\clients\...` 사용.
- 전용 창 브라우저 설정: `%LOCALAPPDATA%\YBY\desktop\...`에 일반 브라우저와 구분된 프로필을 사용합니다.

V4.1.2의 반납/재보고 공통 양식·승인취소 음영·신청/결재 날짜 배치와 V4.1.3의 PowerShell UTF-8 BOM·구문 사전 검사를 유지합니다.

## 검증과 실제 PC 확인

Linux/Python/실제 Chromium에서 아이디 직접 입력, 목록 갱신 중 입력 보존, 실패 안내, 중복 요청 방지, 로그인·로그아웃·재접속·최초 비밀번호 변경, 기존 관리자·지점 권한/정산을 검사했습니다. 작은 화면에서도 입력란 가로 넘침이 없음을 확인했습니다.

Windows 시작 메뉴 등록·Edge/Chrome 창의 실제 크기/위치·회사 정책은 이 환경에서 실행하지 않았습니다. 적용 후 VERIFY_WINDOWS.bat 및 실제 시작 메뉴 실행으로 확인하세요. PowerShell 파일은 모두 UTF-8 BOM을 유지하며 실제 Windows 실행 전에 구문 검사합니다.
