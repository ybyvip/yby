## 실제 확인하지 않은 범위

실제 Oracle 접속, 원천 SELECT·상태코드 매핑·증분 수신·업체 원문 필드·첨부 저장소·실시간 동기화는 아직 구현하거나 시험하지 않았습니다. 수신함은 어댑터 연결 경계이며 배포 시 비어 있습니다. 향후 Oracle 담당자 자료가 도착하면 해당 범위를 별도 구현·검증합니다.

실제 고객 DB 대신 일회용 시험자료를 사용했습니다. 실제 Windows/Edge 전용 창, 회사 인증서 저장소·방화벽·다른 직원 PC 환경은 Linux에서 실행하지 않았습니다. 회사 PC에서 적용 후 로그인·버전·신청일·신청자·이력 표시를 확인해야 합니다.

코어 데이터 형식이 6으로 갱신됩니다. 구버전으로 되돌리려면 업그레이드 전 전체 백업을 사용해야 하며, JSON 자료 내보내기는 외부 수신 원본/첨부를 포함한 전체 복원본이 아닙니다.
