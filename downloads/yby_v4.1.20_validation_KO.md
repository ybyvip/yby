# YBY V4.1.20 검증 결과

검증일: 2026-10-20 (한국시간). 기준 V4.1.19, DB 스키마 8 유지.

## 자동 검사

- Python 서버 전체 **332개 통과**, 실패·스킵 없음, 164.818초.
- Node 이력·통계 **32개 통과**, 실패·스킵 없음. 신규 상태 판정 4개 포함.
- 고유 자동 검사 합계 **364개**. 브라우저 시나리오·반복 검사는 중복 합산하지 않았습니다.
- 기존 최대 2,000행 업로드, 중복·트랜잭션 롤백·지점 권한·정정 버전·전체백업 복구 검사 유지.

## 실제 Chromium 브라우저

- 사용정산 15개 열, 불출반납 18개 열의 **모든 필터 칸**에 실제 선택 목록이 있는지 확인하고 각 선택을 실행했습니다.
- 화살표 선택의 정확 일치, ‘사용’과 ‘미사용’ 구분, 빈 값 선택, 직접 입력 검색, 조건 초기화와 조합 확인.
- 다른 지점 자료를 별도로 반영한 뒤 지점 조회 계정으로 접속하여 선택 목록에 타 지점 값이 없는지 확인. 단순 조회 계정에는 수정 도구 미노출.
- 사용정산이력대장 상단의 대상 선택 → 비밀번호 확인 → 실제 정정 저장으로 두 대장 반영 확인. 표 오른쪽으로 이동할 필요 없이 실행.
- 불출 완료 행에 정산완료/미사용 상태가 섞이지 않고, 반납 행에는 정정된 반납·정산 상태가 표시되는지 확인. 실제 XLSX에서도 동일 문구 확인.
- 두 대장 각각 맞춤/스크롤 선택, 실제 scrollLeft 이동, 메뉴 이동 후 선택 유지 확인.
- 1920/1440/1024/768/390/320px에서 맞춤 표시가 표 영역 폭 안에 들어오는지 확인. 좁은 화면은 열 이름이 붙은 세로형 기록. 문서 전체 가로 넘침 없음.
- 같은 파일을 재업로드한 중복 미리보기에서 **선택 초기화**로 파일·표·체크가 비워지는지 확인. 전후 업무 상태 동일.
- 검사 응답을 지연시킨 후 초기화하여, 늦은 응답이 표를 다시 채우거나 UI를 검사 중으로 고정하지 않는지 확인.
- 저장 요청을 지연시켜 초기화 버튼 잠금 및 저장 중 안내, 이후 정상 완료 확인.
- JavaScript 실행 오류 없음.

## 회귀·첨부 원본

- 이전 V4.1.19의 두 번 업로드·완료 재클릭 안내·부분 선택 후 남은 행 처리·업로드 한정 조회·입력순 번호·모든 열 직접 검색·정정 전후 음영 표·반납 추가·엑셀 출력 회귀 확인.
- 수신함 방식의 신청/정산 수신·매칭·실제 불출/반납 및 법인카드 목록 XLSX/PDF 회귀 확인.
- 기존 직접 이관 확인창 취소·실패 보존·재시도·실제 Excel/PDF 출력과 일반 업무/전체백업 다운로드 확인.
- 이전 실제 Book1.xlsx 제목5행/업무6~9행: 정산이력4 / 불출4 / 반납3 / 금액미기재3 / 합계225,000원 / 재검사 중복4. 원본 대응 항목과 번호/작성기준일 보존 확인.
