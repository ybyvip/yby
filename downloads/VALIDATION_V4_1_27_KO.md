# V4.1.27 검증자료

## 검증 환경 및 원칙

Linux / Python 3.12 / Node.js / 실제 Chromium, 임시 SQLite DB와 가상 최고관리자·지점·최소 권한 계정을 사용했습니다. 회사 운영 서버·DB·계정·실제 인증서는 접속하거나 수정하지 않았습니다.

## 실제 통과

- 전체 서버 회귀시험 **452개 통과**. 기존 권한·비밀번호·지점 격리·자료 이관·대여/반납·결재·첨부·백업·복원·동시 처리 검사 포함.
- 신규 서버 시험 14개: 담당 범위 합계와 식별정보 비노출, 기타 사고 저장/불출 제한/정상 복구, 계정별 메뉴 설정, 후속점검 작성자·최고관리자 허용 및 타인 거절, 숫자 ID/신청자 누락 원문 연결, 중복 원문 임의 선택 차단, 원문 부재 시 보존 스냅샷 조회, 후속 기록 추가와 원 업무 불변, 서식/표 왕복 저장, 부적절한 요소·스타일·외부 그림·과도한 중첩 거절, 소유자·지점·파일 종류별 그림 검증, 중복/동시 상신 단일 기록, 권한 없는 상신 거절과 정적 파일 제공.
- Python 파일 111개 AST 검사와 JavaScript 파일 22개 구문 검사 통과. Node.js 기존 대장·통계 검사 2개 통과.
- 인증·비밀번호 보관·인증서 권한·Windows 설치·LAN 설정 핵심 파일은 V4.1.26 원본과 바이트 단위 동일함을 확인했습니다.
- 읽기 전용 한글 경로 원본에서 쓰기 가능한 실행 폴더로 설치, 실제 서버 시작/로그인/업무 저장, 중복 실행 시 동일 PID 유지, 원본 DB 불변, 재설치 시 실행 폴더의 업무 DB 보존을 Linux에서 통과했습니다.
- 실제 브라우저: 같은 브라우저에서 최고관리자/지점/최소 권한 계정 전환, 허용된 메뉴 열기, 타 권한 메뉴 숨김, 메뉴 선택 후 자동 숨김, 계정별 고정 설정 재로그인 보존, 고정 시 본문 가림 없음, 키보드 이동, 분류 아이콘.
- 실제 브라우저: 사용자별/지점별 조회·검색과 권한 밖 이름 비노출, 확대 그래프·3종 모양·하단 분석, 6개 이상 상태의 서로 다른 색상, 기타 저장 후 상단 합계 갱신.
- 실제 브라우저: 글꼴·크기·굵기·표·로컬 그림 작성, 미리보기 시 업로드/문서 생성 없음, 실제 상신 후 그림/표/서식 열람, 재로그인 후 저장 문서 열람과 인증된 이미지 응답, 일반 텍스트 호환.
- 실제 브라우저: 작성자와 최고관리자의 저장 기록 후속점검 창 열림. 1600/1024/768/390px에서 고정/자동 숨김과 주요 업무 화면 검사. JavaScript 실행 오류 없음.
- 기존 업무 브라우저 회귀: 사고 접수·대체카드·종료 이력, 대여 임시저장/불출 확정/반납, 민원·기안 첨부와 미리보기, 수기정정 열 구성, 점검 완료 시 원 업무 보존 및 실제 XLSX 다운로드.
- V4.1.26 주요 화면 회귀: 원문 강조 연결, 드래그 가능한 창, 상세 공지 등록, 주요 소식 선별, 6종 점검 집계 상세, 개별 대조표 보완/완료 및 누적 이력, XLSX, 반응형 화면.
- 안정화 브라우저: 지점 정책 변경, 자기 결재 사유/비밀번호 확인, 암호화 백업 다운로드, 잘못된/올바른 비밀번호 복원 점검, 권한 격리.
- 실제 Chromium의 시험 CA 신뢰 기반 HTTPS 로그인 및 HTTP→HTTPS 전환, 보안 쿠키, 로그아웃 후 재접속. 인증서 오류 무시 옵션 없이 통과.

## 해석과 미검증 범위

- 일반 계정 메뉴가 완전히 사라지는 현상은 원본 V4.1.26과 제공 가능한 시험 계정에서 동일하게 재현되지 않았습니다. 메뉴 버튼을 헤더에 고정 제공하고, 열 때 권한을 재계산하며, 계정별 고정 선택과 3종 계정 전환을 검증했습니다. 회사의 실제 계정/권한/브라우저 상태로는 추가 확인이 필요합니다.
- 후속점검은 과거 식별 정보 누락·숫자 ID·원문 부재 조건을 재현했습니다. 원문 부재를 권한 오류로 처리하던 흐름을 구분하고, 저장 시점 자료를 조회하게 했습니다. 회사에서 발생한 해당 기록 자체는 확보하지 않았습니다.
- Windows 실기 실행·DPAPI 계정 이동, 회사 서버의 방화벽·백신·공유 폴더·실제 인증서·운영 DB 업그레이드, 사내망 다수 사용자 장시간 부하와 현업 사용성은 미검증입니다.
- 동시 처리 검증은 시험 DB/반복 요청 기준이며 실서버 부하 보장이 아닙니다. Linux에서 수행한 설치·인증서 시험을 Windows 실기 검증으로 해석하면 안 됩니다.
- 글꼴은 설치 환경에 따라 대체 글꼴로 표시될 수 있습니다. 본문 그림은 현재 허용된 첨부 이미지 형식만 지원합니다.

```sh
python -m unittest discover -s tests -v
node --test tests/*.test.cjs
python tests/browser_v4127.py
python tests/browser_v4123.py
python tests/browser_v4126.py
python tests/browser_v4121.py
python tests/browser_tls.py
python tests/bootstrap_smoke.py
```

브라우저 시험에는 Playwright 및 Chromium이 필요합니다. HTTPS 시험은 Linux NSS `certutil`을 사용합니다. 실제 운영 DB에 이 시험을 실행하지 마세요.
