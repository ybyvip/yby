# V3.9.8 전체 실행 패키지

다운로드: [yby_v3.9.8_full_ready.zip](./yby_v3.9.8_full_ready.zip)

원본 V3.9.8 애플리케이션 전체 파일에 Windows/Linux 실행 도우미와 한국어 안내서를 추가한 배포 패키지입니다. 기존 애플리케이션 소스는 변경하지 않았습니다.

1. Python 3.11 이상을 설치하세요. Windows 설치 시 Add Python to PATH를 선택하세요.
2. ZIP을 새 폴더에 전체 압축 해제하세요.
3. Windows는 RUN_WINDOWS.bat을 더블클릭하세요. Linux는 sh RUN_LINUX.sh를 실행하세요.
4. 첫 실행에는 의존성 설치를 위한 인터넷 연결이 필요합니다.
5. 실행 창에 표시되는 임시 비밀번호로 로그인하고 비밀번호를 변경하세요. 서버를 사용할 동안 실행 창을 열어 두세요.

자세한 설명은 ZIP 안의 README_START_KO.md를 확인하세요. 실행 도우미는 로컬 Python 가상환경을 만들고, 종료 직후 포트 해제를 기다린 뒤 서버와 로그인 화면의 준비 상태를 확인합니다. 기본 실행은 이 PC에서만 접속 가능한 로컬 HTTP입니다.

최종 ZIP을 새로 압축 해제한 Linux/Python 3.12 환경에서 의존성 설치, 실제 서버 기동 및 로그인, 서버 테스트 34개 통과를 확인했습니다. 원본 V3.9.8의 브라우저 기능 및 HTTPS 검증도 통과했습니다. 실제 Windows BAT/Edge 실행과 사용자의 업무 데이터 이전은 별도 확인이 필요합니다.

실제 업무 DB, 암호화 키, 첨부파일, 클라우드의 검증 계정과 로그는 포함하지 않습니다. Python이 필요한 전체 소스 배포 패키지이며 EXE 파일은 아닙니다.

파일 무결성을 확인하려면 yby_v3.9.8_full_ready.zip.sha256의 SHA-256 값을 사용하세요.
