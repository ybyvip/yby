# YBY V4.1.10 검증 결과

검증일: 2026-10-19 (한국시간)

- Python 서버 자동 검증 **206개 통과**, 실패·스킵 없음. 새 검증 10개: 적용 상태는 실제 저장 후 변경, 지점/검색/카드별 지표, 원천 갱신/회수, 보고서 초안 읽기 전용·권한·독립 결재·원본 스냅샷·원자적 실패, 미사용 반납, 일반 저장으로 원본 변조 차단.
- Node 이력/집계 검증 **12개 통과**. 자동 검증 합계 **218개**.
- 실제 Chromium에서 문서 클릭이나 갱신 버튼 없이 **10초 주기 신청서·정산서 수신함 표시** 확인. DB에 테스트 문서를 저장한 뒤 실시간 목록 반영을 기다려 확인했습니다. 이는 Oracle 동기화 시험이 아닙니다.
- 신청서 원문 변경 뒤 적용 차단, 단순 선택 시 불출 안 함, 저장 후 적용 상태, 미적용 필터, 다른 지점/카드 제외, 2건 23,000원 명세 입력, 반납 저장 후 보고서 초안 생성/수정/별도 상신, 정산은 승인대기로 유지, 원본 링크와 서버 스냅샷 저장, 나중에 재작성, 로그아웃 뒤 조회 중지·자료 비우기 확인.
- 1440/768/390/320px 수신 목록 가로 넘침 없음. 기존 V4.1.9 신청·출처 선택, V4.1.2 정산/정정/재보고/첨부/본인 정산 결재/인쇄, V4.1.8 이력/보고서/엑셀/PDF/권한 회귀 통과. 브라우저 JavaScript 오류 없음.
- 실제 V4.1.9 → V4.1.10 갱신에서 프로그램 교체 전 DB 바이트 동일, 실행 후 기존 로그인/업무자료/첨부/수신 문서 유지. CA/개인키는 가짜 fixture 바이트 보존 시험이며 회사 인증서 검증을 뜻하지 않습니다. 사내망 설정 보존. 데이터 스키마는 6 유지.
- 읽기 전용 한글 경로 소스 → 사용자 실행 폴더 복사·실제 기동·로그인·업무 저장·중복 실행 같은 PID·원본 DB 보존·재설치 후 자료 유지 통과.
