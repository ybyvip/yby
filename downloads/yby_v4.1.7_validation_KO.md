# YBY V4.1.7 검증 결과

2026년 10월 19일 · Linux / Python 3.12 / 실제 Chromium

## 실행 결과

- 기존 자동검사 **174개 모두 통과**: 76.237초, 실패·건너뜀 없음. 계정·권한·세션, 불출·반납·정산, 승인취소·재보고, 첨부, 인증서·기동 관련 기존 검사를 포함합니다.
- 실제 브라우저에서 관리자 메뉴 **15개 화면**의 이동, 활성 메뉴 표시, 제목색 통일을 확인했습니다. 메뉴 일반 글자는 같은 색이고 선택 메뉴는 흰색입니다.
- 법인카드 메뉴에서 ‘사용정산 이력대장’이 ‘사용 정산 및 결재’ 바로 다음인지 확인했습니다.
- 대시보드의 네 요약 수치 글자색, 바로가기 버튼 색상 통일을 확인했습니다. 관리자와 지점 계정 로그인 및 지점 계정의 관리자 메뉴 숨김도 확인했습니다.
- 로그인 전용 웹 영역 440×690에서 기존 작은 입력 패널 높이 330px 이하를 확인했습니다.
- 정산 브라우저 검사 통과: 두 건 명세·영수증·여러 줄 메모 입력 → 본인 승인 → 승인취소 → 같은 구조의 정정 양식 → 첨부 유지 → 수정·재보고 → 승인.
- 정산 입력창은 1366 / 1024 / 768 / 390 / 320px 폭에서 필드 가로 넘침이 없고, 금액 합계와 직접 입력한 날짜를 유지했습니다.
- 승인취소 행·상태·상세의 음영, 신청/결재 날짜 묶음 및 취소 날짜, 인쇄 날짜 표시와 HTML 특수문자 처리를 확인했습니다.
- 위 브라우저 검사에서 JavaScript 실행 오류가 없었습니다.
- 읽기 전용 한글 경로의 원본을 사용자 실행 폴더로 복사하는 기동 검사를 통과했습니다. 실제 서버 시작·로그인·카드 저장, 중복 실행 시 기존 PID 유지, 원본 DB 불변 및 재설치 후 실행 자료 보존을 확인했습니다.
- 최종 ZIP의 CRC, 전체 MANIFEST SHA-256과 Python 3.11 구문 호환성, PowerShell UTF-8 BOM을 검사했습니다. 배포 파일 목록을 고정하여 시험 DB·첨부·로그·개인키가 들어가지 않도록 했습니다.

화면 변경은 `templates/index.html`의 메뉴 순서, 일반 장식색, 화면용 스타일입니다. Python 서버·기동 파일은 버전 식별자만 갱신했으며 DB 스키마와 업무 저장 로직을 변경하지 않았습니다. 기존 PowerShell과 인증서·클라이언트 실행 스크립트는 V4.1.6과 바이트가 같습니다.

## 플랫폼 제한

실제 Windows / Edge 전용 창, 회사 방화벽, 다른 회사 PC 접속은 이 Linux 환경에서 실행하지 않았습니다. 회사 PC에서 적용 후 V4.1.7 표시와 접속을 확인하세요. 제공한 검증 결과는 실제 고객 DB에 대한 검사가 아니며 일회용 시험 계정·자료로 수행했습니다. Oracle 연동은 이번 버전에 구현하거나 시험하지 않았습니다.

로그인 날씨 제공자의 실시간 응답은 이번 화면 변경 검사의 대상이 아닙니다. 정산 브라우저 검사에서 사용한 날씨 응답은 시험값 또는 미수신 상태이며 로그인·업무 화면 사용에는 영향을 주지 않습니다.
