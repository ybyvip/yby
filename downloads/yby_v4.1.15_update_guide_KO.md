# YBY V4.1.15 업데이트·사용 안내

작성일: 2026-10-20 (한국시간). 기준 버전: V4.1.14.

## 업데이트

1. 최고관리자로 **시스템 관리 → 권한 & 비밀번호 관리 → 전체 백업 만들기**를 실행합니다. 현재 로그인 비밀번호로 확인하고, Ctrl+J에서 백업 ZIP 다운로드 완료를 확인해 별도 보관하세요. 상단의 ‘데이터 백업’ JSON과 다릅니다.
2. 다른 사용자의 작업을 마친 뒤 기존 서버 실행창에서 **Ctrl+C**로 종료합니다.
3. 전체 패키지를 **새 폴더에 완전히 압축 해제**합니다. 기존 서버와 **같은 Windows 계정**에서 **RUN_LAN_WINDOWS.bat**를 실행하세요.
4. 실제 실행 위치 `%LOCALAPPDATA%\YBY\app`의 업무 자료·계정·첨부·인증서·사내망 설정을 유지하면서 프로그램을 교체합니다. 정상 업데이트에는 백업을 복원하지 않습니다.
5. 상단 **V4.1.15**와 기존 자료를 확인합니다. 이전 화면이 보이면 창을 닫고 CONNECT_SERVER.bat로 다시 여세요. 서버 실행창은 계속 열어 둡니다.

서버 PC는 `https://localhost:5000`, 다른 PC는 서버 IP가 그대로라면 `https://10.10.0.121:5000`입니다. HTTP가 아니라 HTTPS를 사용하세요.

DB 스키마는 **6 → 7**로 올라가며 매칭·매칭 이력 테이블을 추가합니다. 시작 전 자동 전체 백업도 생성합니다. 기존 불출·정산·외부 원문·하이패스 이력을 다시 쓰거나 자동 매칭하지 않습니다. 이전 프로그램은 최신 DB를 직접 열 수 없습니다. 이전 버전으로 돌아갈 때는 서버 종료 후 업데이트 전 전체 백업과 해당 이전 프로그램을 함께 사용해야 합니다. 백업 복원은 현재 자료를 이전 시점으로 돌리는 작업이므로 정상 업데이트에서는 실행하지 마세요.

## 1. 사용 정산 및 결재 화면

별도 정산 입력창을 없애고 **외부 정산서 수신 목록 + 기존 정산 결재 목록**으로 구성했습니다. 반납 화면과 동일한 수신 목록이 10초마다 서버 수신함을 확인하며 ‘지금 갱신’도 지원합니다.

- 문서를 선택하면 내용을 확인합니다. 이미 신청서와 매칭됐고 실제 불출 중이면 **그 불출 건의 반납·사용정산 화면**으로 이어집니다.
- 아직 매칭되지 않았으면 ‘신청서와 매칭’으로 연결할 수 있습니다. YBY에서 직접 불출한 건은 해당 지점·카드 끝자리의 후보 중 실제 카드·사용자를 직접 확인하고 반납·정산할 수도 있습니다.
- 선택만으로 반납·정산이 저장되지 않습니다. 입력 내용을 검토한 뒤 기존 **반납 및 정산 신청**으로 저장합니다.
- YBY 직접 불출과 반납 시 직접 정산 작성은 계속 사용할 수 있습니다. 이미 반납된 건을 다시 반납하거나 외부 문서를 중복 적용하지 않습니다.

## 2. 외부자료 매칭

법인카드 관리의 **외부자료 매칭**에서 독립적으로 작성된 외부 신청서 1건과 정산서 1건을 연결합니다.

### 새 연결

1. 좌측 신청서와 우측 정산서를 각각 선택합니다. 문서번호·신청자 검색, 원문 내용 확인, 이전/다음 조회를 지원합니다.
2. **지점·실사용자·사용 기간·목적·카드**를 비교하고 ‘두 문서가 같은 사용 건임을 확인했습니다’를 체크합니다.
3. 필요하면 메모를 입력하고 **매칭 저장**을 누릅니다.
4. 하단 연결 목록에서 **불출 준비** 또는 **반납·정산**으로 이어갑니다. 불출은 관리자가 실제 카드를 선택·확인한 뒤 적용합니다.

신청서와 정산서에는 공통 연결번호가 없으므로 **문서번호가 같거나 카드 끝자리가 같다는 이유로 자동 연결하지 않습니다.** 같은 지점의 문서만 연결하며, 이미 다른 문서와 연결된 자료의 중복 연결을 차단합니다. 실제 불출 연결은 신청서 원문 키·지점·불출 이력 ID·카드번호로 확인합니다. 카드 끝자리만으로 과거 불출과 새 불출을 섞지 않습니다. 외부 결재 상태는 참고 표시이며 YBY 결재는 별도로 진행합니다.

### 잘못된 매칭 수정·해제

- **반납·정산 저장 전**: ‘매칭 수정’에서 두 문서를 다시 선택하고 확인합니다. **변경 사유 + 현재 로그인 비밀번호**가 필요합니다. ‘연결 해제’도 같은 확인을 거칩니다. 원문과 기존 불출 이력은 삭제하지 않습니다.
- 다른 담당자가 먼저 변경했거나 원문이 새 버전으로 갱신되면 다시 조회·확인해야 합니다. 외부에서 회수·삭제된 문서는 새 처리에 적용하지 않습니다.
- **반납·정산 저장 후**: 매칭 수정·해제를 잠급니다. 잘못 저장한 내용은 기존 **승인취소·정정 → 정정 작성·재보고 → 결재** 절차를 이용합니다. 저장된 원문 연결·스냅샷은 감사 근거로 보존하며 과거 원문을 몰래 교체하지 않습니다.
- ‘이력’과 **전체 변경 이력**에서 등록·수정·해제의 처리자·일시·사유·변경 전/후 문서를 확인하고 인쇄/PDF로 보관할 수 있습니다. 연결을 해제한 과거 이력도 남습니다.

최고관리자는 전체 지점, 지점 사용자는 자기 지점 자료만 조회·처리합니다. 기존 불출·반납 또는 정산 권한이 있으면 매칭 화면을 사용할 수 있고, 권한 설정에서 ‘외부자료 매칭’만 별도 지정할 수도 있습니다. 실제 불출·반납은 해당 권한이 추가로 필요합니다. 단순 조회 권한만으로 자료를 변경할 수 없습니다.

## 3. 하이패스 이력 상태 색상

등록·변경 이력에서 같은 묶음의 **최종 현재 상태**인 ‘대기중’은 연한 황색, ‘불출중’은 연한 청색으로 구별합니다. 상태 글자도 함께 표시합니다. 과거 행은 당시 작업 완료 표시를 유지합니다.

## 4. 전체 통계

**정산 및 통계 → 통계 및 보고서 → 전체 통계**가 기본 선택입니다.

- 승인 정산 문서 수 / 사용 횟수 / 승인 사용금액 / 비교월 대비 증감액을 표시합니다.
- 지점별·부서별·개인별·목적별 간결한 요약표와 **지점 → 부서 → 개인 → 목적** 통합 비교표를 제공합니다.
- 기준월·비교월·카드사·카드 조건을 적용하며 지점 사용자는 자기 지점만 집계합니다. 기존 네 가지 개별 통계도 유지합니다.
- 전체 통계 **엑셀**에는 네 가지 요약과 통합 비교 내역을 함께 담습니다. 인쇄/PDF도 지원합니다.
- **승인완료인 유효 문서만** 집계합니다. 승인취소·이전 정정·재보고로 대체된 자료와 과거 마이너스 정정 자료를 제외하고, 같은 정산 문서가 신청 목록과 이력에 함께 있으면 이력을 우선해 한 번만 계산합니다.
- 사용 횟수는 건별 명세 수이며, 수량 합계나 불출 횟수가 아닙니다. 예전 명세 없는 정산은 문서당 1회입니다. 월은 정산 문서의 사용일 기준입니다. 여러 목적이 선택된 문서는 하나의 복합 목적 분류로 처리해 금액을 반복 합산하지 않습니다.
- 네 가지 요약표는 **같은 총액을 다른 기준으로 나눈 표**입니다. 네 표의 금액을 다시 합산하지 마세요. 비교월에만 사용한 항목도 비교표에 표시됩니다.

## Oracle 연결과 검증 범위

이번 버전은 **YBY 서버 수신함에 저장된 정규화 문서**의 조회·매칭·처리를 구현합니다. 실제 Oracle 연결은 담당자의 조회용 SQL/뷰·컬럼·권한 자료를 받은 뒤 연결합니다. 현재 회사 Oracle DB를 실시간 수집한다고 표시하지 않습니다. 비밀번호·DB 접속정보를 다운로드 패키지에 넣지 않았습니다.

자동 검증과 실제 Chromium 검증 결과는 **VALIDATION_V4_1_15.md**를 참조하세요. 회사 Windows/Edge/WebView2, 회사 인증서·방화벽 및 실제 Oracle 접속은 이 환경에서 실행하지 않았으므로 회사 PC에서 최종 확인이 필요합니다.
