# V4.1.28 검증자료

## 검증 환경

Linux / Python 3.12 / Node.js / 실제 Chromium / 임시 SQLite DB와 가상 계정으로 시험했습니다. 원본 V4.1.27 ZIP에서 별도 작업 폴더를 만들었습니다. 회사 운영 서버·DB·실제 계정·인증서는 접근하거나 변경하지 않았습니다.

## 실제 통과

- **서버 시험 463개 통과**: 기존 452개와 신규 11개. 권한·지점 격리·동시 처리·자료 이관·대여/반납·정산·결재·첨부·백업·복원·계정 보존 포함.
- 신규 서버 시험: 여섯 점검 기준과 실제 목록 건수 일치, 절차·준비자료·주의사항 제공, 빈 결과·페이지 이동·권한 없는 조회 거절, 안내 열람 시 업무 원문 불변.
- 신규 서버 시험: 한국 날짜의 월요일~일요일 주간, 주중 선정 유지, 다음 주 두 사진 변경, 계절별·날씨 장애 기본 선정, 오래된/알 수 없는/시간대 없는 날씨를 현재 참고 정보로 표시하지 않음, 계정·기기 간 동일 선정, 최초 동시 조회 시 한 주 기록 1개, 기존 로컬 이미지 응답, 새 정적 파일 제공.
- 저장 형식 15→16 적용 시 계정 비밀번호 해시·기존 문서 및 이력·주간 사진 기록 보존 확인.
- **실제 브라우저**에서 두 대장의 평상시 화살표 숨김, 마우스·키보드 접근 표시, 칸보다 넓은 선택창, 200자를 넘는 전체 선택값의 줄바꿈·정확한 값 선택·직접 검색·목록 내 검색·0건·조건 초기화·Escape를 확인했습니다.
- 키보드 포커스 이동의 자동 스크롤로 열린 창이 닫히는 문제를 발견해 수정했습니다. 실제 위치 변경과 포커스로 발생한 스크롤 알림을 구분하며, 화면 모서리에서 선택창을 화면 안에 배치하는 것을 재검증했습니다.
- 카드 조회 현황: 최고관리자의 전체/지점/검색어/빈 결과/삭제 보존 포함·제외 조합에서 표시 매수를 실제 표와 대조했습니다. 일반 계정의 담당 지점 제한, 사용가능·대여중의 선두 배치도 확인했습니다.
- 주간 사진: 실제 로컬 이미지 로딩, 비·눈 선정 참고 조건, 주중 동일 사진 유지 및 월요일 다음 사진 전환, 두 작성 화면의 사진 표시, 기존 위로 문구 유지. 사진 API의 503 장애를 재현하여 기본 로컬 사진과 보고서 본문 입력의 정상 동작을 확인했습니다.
- 여섯 점검 지표를 실제 클릭하여 각 업무의 집계 기준·준비자료·6단계 절차·주의사항이 실제 목록 위에 표시되는 것과 목록 이동을 확인했습니다. 원문·반납·승인 상태 및 점검 기록이 그대로임을 비교했습니다.
- 화면 너비 **1600/1024/768/390px**, 터치 방식 390px에서 선택창 경계·가로 넘침·직접 터치 선택을 확인했습니다. 최소 권한 계정으로 바꾼 뒤 이전 선택창 값이 남지 않으며 점검 API가 거절됨을 확인했습니다. JavaScript 실행 오류 없음.
- 기존 브라우저 회귀: 사고 접수·대체카드·종료 이력, 대여 임시저장/불출 확정/반납, 민원·기안 첨부와 미리보기, 수기정정 열 구성, 점검 완료 시 원 업무 보존과 실제 XLSX.
- 기존 브라우저 회귀: 일반 계정·최고관리자의 메뉴/고정/숨김·아이콘, 사용자별/지점별 그래프, 사고 상태별 색상과 상단 매수, 서식·표·그림 보고서의 실제 상신/재접속/열람, 작성자·최고관리자의 후속점검, 드래그 창·공지·원문 강조·세부 점검·누적 기록.
- Python 파일 **115개** AST 검사, JavaScript 파일 **23개** 구문 검사, 기존 Node 대장·통계 시험 **2개** 통과.
- 읽기 전용 한글 경로의 원본에서 실행 폴더로 설치 후 실제 시작·로그인·업무 저장, 중복 시작 시 동일 PID 유지, 원본 DB 불변 및 재설치 시 실행 폴더 자료 보존을 확인했습니다.
- 실제 Chromium에서 시험 CA를 신뢰한 HTTPS 로그인, HTTP→HTTPS 전환, 보안 쿠키 및 로그아웃 후 재접속을 인증서 오류 무시 없이 통과했습니다. Linux 시험이며 Windows 실기 검증은 아닙니다.
- 인증·비밀번호 보관·인증서 권한·Windows 설치·LAN 설정 핵심 파일, 대여/사고 및 업무점검 변경 처리와 보고서 서식 검증 핵심 모듈이 원본 V4.1.27과 바이트 단위 동일함을 확인했습니다.

## 미검증 및 사용상 해석

- 회사 운영 DB 업그레이드, 실제 회사 계정의 업무 자료, Windows·Edge/WebView2 실기, 회사 방화벽·보안 프로그램·인증서·공유 폴더, 장기 운영·다수 사용자 부하는 미검증입니다. 시험 DB의 동시 요청 검증이 실제 서버의 부하 보장을 뜻하지 않습니다.
- 날씨 분기와 주간 전환은 시험 시각·날씨 응답으로 재현했습니다. 회사 서버에서 청주시 날씨를 실제 수신할 수 있는지는 별도 확인해야 합니다. 네트워크가 막히면 계절 기준 사진을 사용합니다.
- 기존 로컬 사진을 주 단위로 순환하므로 시간이 지나면 예전에 본 사진이 다시 나올 수 있습니다. 사진은 선정 당시 날씨·계절을 참고한 분위기용 풍경이며 실제 현장 기상 사진이 아닙니다.
- 선택창의 긴 글씨는 화면 폭에 맞게 줄바꿈합니다. 항목이 많거나 글이 매우 길면 목록 안에서 세로 스크롤하거나 목록 내 검색을 사용합니다. 터치 기기는 마우스가 없으므로 화살표를 계속 표시합니다.
- 점검 절차는 현재 프로그램 기능을 사용하는 안내입니다. 회사 회계·카드사·독립 결재 업무를 자동 수행하거나 회사 내규를 대신하지 않습니다.
