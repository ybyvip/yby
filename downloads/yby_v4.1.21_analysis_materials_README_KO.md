# YBY V4.1.21 분석자료 2종

작성일: 2026-10-20 · 한국시간

이 묶음은 분석자료이며 프로그램 수정판이 아닙니다. 두 자료는 PDF·Word·Markdown으로 같은 내용을 제공합니다. Word의 페이지 수는 편집기/글꼴에 따라 달라질 수 있습니다.

| 자료 | PDF 분량 | 주요 내용 |
|---|---:|---|
| 카드관리 보조업무·사용내역·통계 분석자료 | 14쪽 | 본사/지점 실물 불출·반납, 별도 정산시스템과 역할 구분, 사용내역/대장/통계/현황, 경계 사례와 보완 우선순위 |
| 회사 업무용 적합성·완성도 분석자료 | 15쪽 | 도입 판단, 전체 기능, 보안/권한, 백업/복구, 운영/성능, 유지보수, 인수 체크리스트 |

권고: 통제 조건을 충족한 사내 카드관리 보조업무 시범 운영은 검토할 수 있습니다. 현재 사용 반납은 YBY 정산과 결합되어 있으므로, 외부만 정산하는 업무의 정식 확대 전 독립 실물 반납·통합 읽기전용·분실/정지 상태와 통계 기준을 보완해야 합니다.

이번 직접 검증: Python365개 + Node32개 = 고유397개 통과. Chromium의 정책/업무점검/암호화 복원과 대시보드·5개 통계 차원·실제 Excel 확인. 보조관리8관찰/통계7관찰은397개에 중복 합산하지 않습니다. 기존 배포 기록으로만 참조한 항목은 evidence/existing_release에 분리했습니다.

회사 실제 Windows/Oracle/회사 DB·장기 운영·독립 침투시험은 미확인입니다. 분석자료가 운영 승인/회계 확정/무결함 보증을 대신하지 않습니다.

증거 폴더의 계정/암호 문자열은 합성 시험 전용입니다. 회사 업무 자료·인증서/개인키는 포함하지 않았습니다. 의도된 오류 주입 시험의 ERROR 로그는 정상 검사 과정이며 최종 판정을 확인하세요.

manifest-sha256.json은 묶음 내부 파일 해시입니다. 외부 checksums.json은 최종 PDF·Word·Markdown·전체묶음의 해시입니다.
