## 실제 연결 및 플랫폼 한계

청주시 실제 예보 API 접속을 시도했으나 개발 환경의 네트워크 정책이 `api.met.no`의 HTTPS CONNECT를 **403 Forbidden**으로 차단했습니다. 따라서 실제 제공자의 최신 청주시 예보 응답 및 API 운영 상태는 이 환경에서 확인하지 못했습니다. 정상 예보 흐름은 시험 응답으로, 차단 시 로그인 유지/시간대 배경은 실제 차단 환경과 시험 응답으로 확인했습니다. 회사 서버에서 날씨 기능을 사용하려면 해당 HTTPS 서비스에 연결할 수 있어야 합니다. 인증서 검증과 네트워크 보안 설정을 우회하지 않았습니다.

실제 Windows 창 크기·배율·다중 모니터·시작 메뉴·Edge 앱 모드·회사 네트워크는 Linux에서 실행하지 않았습니다. 패키지의 VERIFY_LOGIN_WINDOW_WINDOWS.bat, VERIFY_WINDOWS.bat 및 다른 PC의 CHECK_CONNECTION.bat를 해당 PC에서 사용할 수 있습니다. 자료 보존 검사는 고객 실제 DB가 아닌 일회용 시험자료로 수행했습니다.
