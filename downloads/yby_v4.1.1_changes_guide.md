# V4.1.1 정산 취소·정정·재보고 및 공지 첨부 개선

## 승인 취소와 재보고 흐름

승인완료 이력의 **승인 취소·정정**을 누르면 다음 순서로 처리합니다.

1. 최고관리자가 **취소 사유/정정 요청 메시지**와 현재 관리자 비밀번호를 입력합니다. 본인 정산도 처리할 수 있습니다.
2. 원본 금액·사용 내역·원승인자/시각은 보존하고 상태를 **승인취소**로 기록합니다. 취소자/시각/사유도 별도로 남습니다. 새로운 마이너스 승인완료 자료는 만들지 않습니다.
3. 자동으로 **사용 정산 및 결재** 화면으로 이동하며, 연결된 **재보고대기** 건이 표시됩니다. 별도 **재보고·결재 메시지** 열에서 정정 요청을 확인할 수 있습니다.
4. 최고관리자 또는 원래 신청자가 **정정 작성·재보고**를 눌러 사용 목적·사용자·부서·건별 명세·금액·증빙을 보완합니다. 기존 증빙은 체크하면 유지하며 새 증빙도 추가할 수 있습니다. 지점 사용자는 본인의 정산만 수정할 수 있습니다.
5. **재보고 메시지**를 작성하고 **재보고하여 결재 요청**을 누릅니다. 이때에만 **승인대기**로 전환됩니다. 수정 전 대기 건을 바로 승인할 수 없습니다.
6. 최고관리자가 승인 또는 반려합니다. 본인 정산의 승인·반려도 허용하며 처리자를 기록합니다. 재보고 건의 반려에는 사유가 필요합니다.
7. 반려된 이력의 **수정 후 재보고**로 다시 보완할 수 있습니다. 각 차수와 원본 연결, 취소·재보고·반려·승인 메시지를 상세 화면과 인쇄에서 확인할 수 있습니다.

정산 상태는 `승인완료 → 승인취소(원본 이력) + 재보고대기(새 작업) → 승인대기 → 승인완료/반려됨`입니다. 반려 건은 다시 재보고대기로 만들 수 있습니다. 원본·각 반려본·각 취소본을 삭제하거나 금액을 덮어쓰지 않습니다.

통계는 **현재 승인완료 자료만** 집계합니다. 취소·재보고대기·반려 금액은 승인 사용액에 포함하지 않고, 최종 재승인 금액만 한 번 포함합니다. 이력대장의 금액은 각 문서의 기록이므로 상태와 함께 확인하세요. 기존 버전에서 생성한 마이너스 정정 기록은 임의로 변경하지 않고 보존합니다. 이미 이전 방식으로 정정된 건에 중복 취소를 만들지 않습니다.

재보고는 원래 카드가 등록된 상태에서 진행하며, 카드·지점·원신청자 연결은 유지합니다. 해당 카드가 삭제된 경우 등록 상태를 확인한 뒤 처리하세요.

## 공지사항 첨부

V4.1.0은 상세 화면에서 링크 전체를 HTML 문자로 바꿔 출력하여 실제 링크를 클릭할 수 없는 코드가 있었습니다. 이제 파일명/주소를 안전하게 처리하면서 **파일 열기**와 **다운로드** 링크를 표시합니다. PDF·이미지는 브라우저에서 열 수 있고, 다운로드 링크는 파일 저장을 요청합니다. HWP/Excel 등은 설치된 연결 프로그램에서 여세요.

- 최고관리자가 공지 관리에서 제목·본문과 관련 파일(최대 20MB)을 선택해 등록합니다.
- 공지 저장은 전용 서버 API로 처리합니다. 저장 실패 시 제목·본문·첨부 선택을 유지하고, 같은 파일을 재시도할 때 불필요하게 다시 업로드하지 않습니다. 서버에 저장하지 못한 공지를 성공한 것처럼 화면에 추가하지 않습니다.
- 새 공지용 첨부는 최고관리자가 업로드하고 게시한 후 로그인 사용자에게 제공합니다. 새 첨부는 게시 전/공지 삭제 후에 공지 링크만으로 읽을 수 없습니다. 이전 버전의 정상 첨부도 계속 지원합니다.
- 파일명의 한글·특수문자와 실제 다운로드 바이트, 로그인/관리자 권한, 실패 후 재시도 경로를 검증했습니다.

## 기존 자료를 유지하는 설치

1. 업무 작업을 마무리하고 ZIP을 **새 폴더**에 전체 압축 해제합니다.
2. 새 폴더의 **STOP_SERVER.bat**로 기존 서버를 종료합니다.
3. **RUN_LAN_WINDOWS.bat**를 일반 더블클릭합니다. AppData의 실제 자료·계정·비밀번호·인증서를 유지합니다. 첫 자료 업데이트 전에 전체 백업을 자동 생성하며 자료가 크면 시간이 걸릴 수 있습니다.
4. 새 버전 확인 후 **OPEN_LAN_CLIENT.bat**로 새 LAN_CLIENT.zip을 다른 PC에도 배포하세요. 새 접속 도구를 한 번 실행하면 기존 로그인 바로가기를 갱신합니다.
5. 서버는 **VERIFY_WINDOWS.bat**, 다른 PC는 **CHECK_CONNECTION.bat**로 실제 Windows/회사망을 확인하세요. 서버 실행 창은 열어 둡니다.

재보고 상태를 인식하지 못하는 구버전에서 새 DB를 처리하지 않도록 자료 형식을 버전 5로 표시합니다. 원본을 삭제하거나 구버전으로 억지 변환하지 않습니다. 문제가 있으면 업데이트 전 전체 백업과 진단을 보존하세요.

바탕화면 로그인 바로가기, HTTP→HTTPS 이동, 접속 유지, 최고관리자 재인증 후 현재 비밀번호 표시, 건별 정산 양식은 유지합니다. 검증 범위/한계는 VALIDATION_V4.md에 있습니다.
