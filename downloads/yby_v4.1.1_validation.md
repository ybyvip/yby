# YBY V4.1.1 수정·검증 보고서

2026년 10월 16일(한국 시간). 기준: V4.1.0 전체 패키지. 대상은 최고관리자의 본인 정산 취소, 사유를 남기는 정정·재보고·재결재, 공지 첨부입니다.

## 원인과 구현

- V4.1.0의 정정 API는 신청자와 관리자가 같으면 거부했습니다. 기존에는 반대 금액의 승인완료 기록을 추가했으며 새 정산 작성/재보고 단계가 없었습니다.
- 새 흐름은 원본의 금액·명세·원승인 정보를 보존한 채 승인취소 상태와 취소 사유·취소자/시각을 기록합니다. 별도 연결된 재보고대기 건을 만들고 원신청자 또는 최고관리자가 수정·재보고합니다. 재보고 메시지는 필수이며, 이후에만 승인/반려할 수 있습니다. 최고관리자의 본인 취소·수정·승인·반려를 지원합니다.
- 반려 후 재작성도 지원하고 원본 참조·차수·처리 메시지·처리자·시각을 보존합니다. 수정 사유/재보고/승인/반려는 전용 서버 경로에서만 기록하며 일반 상태 저장으로 우회하지 못하게 합니다.
- 새 취소는 마이너스 승인완료 자료를 만들지 않습니다. 통계는 승인취소/재보고대기/반려를 제외하고 최종 승인 금액만 집계합니다. 이전 버전의 이미 확정된 마이너스 정정 기록은 보존합니다.
- 원래 신청자의 정산 증빙은 최고관리자가 수정할 때도 유지할 수 있으며, 추가 파일은 소유자/정산 지점/용도를 검증합니다. 카드 연결·원신청자는 임의 변경하지 않습니다.
- 공지 상세에서 링크 HTML 전체를 다시 escape하는 오류를 수정했습니다. 개별 파일명·주소는 escape하고 실제 열기/다운로드 링크를 제공합니다. 다운로드 요청은 인라인 MIME과 관계없이 저장 응답을 지원합니다.
- 공지 등록/삭제를 서버 트랜잭션과 중복 방지 요청으로 처리합니다. 실패 시 입력/파일을 유지하고, 파일 업로드는 성공했으나 공지 저장이 실패한 경우 같은 파일로 재시도할 수 있습니다. 새 공지용 파일은 역할·용도·게시 여부를 검증합니다.
- 새 재보고 상태를 구버전이 잘못 처리하지 않도록 자료 형식 5로 표시하고 구버전 실행 보호를 사용합니다. 첫 변환 전에 기존 DB·첨부/키를 전체 백업합니다. 초기 백업 시간을 고려해 서버 준비 대기와 진행 안내를 보완했습니다.

## 검증

- **158개 단위/API/회귀 테스트**: 기존 138개와 새 흐름·공지 첨부 20개. 이전의 마이너스 생성 기대는 원본 보존·재보고대기·통계 제외 검증으로 바꿨으며 기존 데이터 회귀는 유지합니다.
- 새 검사: 최고관리자 본인 취소/재승인, 사유·재인증, 수정 전 승인 거부, 재보고 메시지 필수, 금액 수정 및 승인 합계, 반려·보완 재보고 반복, 원본 메시지의 후속 변경 방지, 신청자/다른 계정의 권한, 동일 요청 재전송·실제 병렬 취소의 단일 처리, DB 장애 시 원복, 일반 저장/위조 메시지 차단, 기존 증빙 유지, 기존 마이너스 기록 보존.
- 공지 검사: 실제 바이너리 업로드, 게시 전 접근 제한, 게시 후 다른 로그인 사용자 열기/다운로드, PDF MIME/헤더와 한글 파일명, 바이트 일치, 로그인/관리자 역할, 다른 용도 파일 연결 차단, 삭제 후 새 공지 첨부 접근 차단, DB 저장 실패 후 같은 파일로 재시도.
- 실제 Chromium UI: 실패한 공지 등록에서 제목/본문/첨부 선택 유지, 재시도 시 업로드/공지 중복 없음, 다른 지점 사용자가 클릭 가능한 링크로 파일 다운로드, 원본 바이트 확인. 최고관리자 본인 취소 → 정정 금액 → 재보고 → 반려 → 보완 재보고 → 승인, 상세 메시지와 원본/각 차수 보존, 최종 승인 금액만 통계 집계, 원신청자의 재보고를 확인했습니다.
- V4.1.0 업무 UI 회귀: 접속 유지·관리자 비밀번호 재인증 표시·화면 이탈 삭제·늦은 응답 폐기, 기존 건별 정산/본인 승인/엑셀, 문서/민원/공지/채팅/하이패스/백업/모바일·키보드·JS 오류 부재.
- 실제 V4.1.0 → V4.1.1 업데이트: 실행 중 코드 교체 방지, 종료 후 업데이트, 기존 비밀번호·시험 업무 자료·CA/키 보존, 변환 전 백업, 새 자료 형식과 구버전 차단, HTTP→HTTPS 및 새 버전 로그인.
- 최종 다운로드 ZIP: CRC·안전한 경로·MANIFEST 전 파일 SHA-256·고객 DB/인증서/키/로그 미포함, PowerShell 문법/Python 3.11 구문, 압축 해제본에서 전체 테스트·새 브라우저 흐름·HTTPS 재접속·bootstrap·사설 IP 재시작 확인. 최종 해시와 결과는 별도 package_verification.json에 기록합니다.

## 실제 확인이 필요한 범위

실행 환경은 Linux/Python 3.12/Chromium입니다. 고객 운영 DB는 제공되지 않아 임시 시험 DB/첨부/업무 자료를 사용했습니다. 실제 Windows 10/11·Python 3.14·NTFS/DPAPI·Edge 전용 창·회사망/VPN·보안 정책을 이 클라우드에서 실행했다고 주장하지 않습니다.

서버 VERIFY_WINDOWS.bat와 클라이언트 CHECK_CONNECTION.bat로 실제 Windows/회사망을 확인할 수 있습니다. 변경된 업무 화면은 운영 자료를 보존한 상태에서 시험 정산과 공지 첨부로 현장 확인하세요. 자료가 큰 경우 첫 전체 백업이 완료될 때까지 서버 실행 창을 유지하세요. 회사 정책이 등록/통신/파일 열기를 막는 경우 IT 담당자의 설정 확인이 필요합니다.
