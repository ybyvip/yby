# YBY V4.1.28 — V4.1.27 기반 검색·현황·작성 안내 개선

기준 ZIP: `yby_v4.1.27_full.zip` / SHA-256 `f3e83ed14fb134bc6a7860a87286a29207ae7c2d0d4bf2a7b32809e3d69350c2`.

## 1. 두 이력대장의 검색 선택창

사용정산 이력대장과 불출/반납 이력대장의 **각 열 아래 검색칸**을 정리했습니다.

- 평소에는 고정된 화살표를 숨깁니다. 검색칸에 마우스를 올리거나 키보드 포커스를 주면 작은 화살표가 나타납니다.
- 화살표에 마우스를 올리거나 클릭하면 선택 목록을 엽니다. 검색칸에서 아래 방향키로도 열 수 있습니다. 터치 환경에서는 화살표를 계속 표시합니다.
- 목록을 좁은 표 칸 밖에 독립적으로 표시합니다. 글씨 길이에 맞춰 폭을 넓히고 화면보다 긴 내용은 줄바꿈합니다. 기존 200자 표시 제한 대신 전체 값을 읽을 수 있습니다.
- 화면 아래쪽에서는 위쪽 여유 공간을 활용해 목록이 잘리지 않게 합니다. 세로로 긴 목록은 목록 안에서 스크롤합니다.
- 목록 내 검색, 방향키 이동·Enter 선택, Escape 닫기, **전체** 선택으로 조건 해제를 지원합니다. 값이 많으면 처음 100개를 표시하며 검색으로 나머지 값도 찾을 수 있습니다.
- 직접 입력하는 부분 검색과 목록에서 선택하는 정확한 값 검색의 기존 의미를 유지합니다. 빈값과 공백도 별도 표시합니다.
- 상단 상세 검색 조건의 화살표도 마우스·키보드 접근 시 표시하도록 정리했습니다. 화면 이동·계정 변경 시 열린 목록을 정리하며, 로그인 권한 및 이관 배치 범위 밖의 선택값을 제공하지 않습니다.

## 2. 등록 법인카드 조회 현황

- 등록된 법인카드 리스트에서 **전체 지점 이외의 지점**을 선택하거나 검색어를 입력하면, **삭제 보존 카드도 보기** 옆에 해당 조회 결과의 카드 현황을 표시합니다.
- 조회 매수, 사용가능, 대여중, 기타, 삭제 보존 매수를 표시합니다. 표와 동일한 필터 함수를 사용하므로 검색어·지점·삭제 보존 체크 변경에 함께 반응합니다. 조회 0장도 명확히 표시합니다.
- 일반 계정은 담당 지점으로 제한되며 해당 범위의 현황을 표시합니다.
- **현재 사용가능 카드 간략 현황**은 사용가능 → 대여중 → 나머지 사유 순으로 배치합니다. 0장인 경우에도 앞의 두 구분을 유지합니다.
- 종료 카드는 활성 합계에서 제외합니다. 대여 중 사고 접수 카드는 대여중에 포함하고 사고 상세 상태는 기존 목록에서 확인합니다. 남은 활성 카드는 관리 제한·만료 등 대표 사유로 분류하여 중복 계산하지 않습니다.
- 위 간략 현황은 로그인 범위 전체, 삭제 보존 체크 옆의 조회 현황은 현재 리스트의 필터 결과입니다.

## 3. 작성 화면 우측의 주간 사진

민원 및 고충게시판과 보고서 작성 및 기안의 우측 그림을 실제 사진으로 변경했습니다. 기존 패키지에 포함된 로컬 풍경 사진을 재사용하며, 외부 이미지 사이트나 추가 이미지 다운로드가 필요하지 않습니다.

- 한국 시간 기준 월요일~일요일을 한 주로 봅니다. 해당 주에 처음 표시할 때 계절과 기존 **청주시 날씨** 참고 정보를 이용해 사진을 선정하고 서버에 보존합니다.
- 같은 주에는 날씨가 달라지거나 다른 계정·기기로 접속해도 같은 사진을 유지합니다. 새 주에는 이전 주와 다른 사진을 선정하며, 두 작성 화면도 서로 다른 사진을 사용합니다.
- 날씨 정보를 받지 못했거나 오래된 정보라면 계절 기준으로 선정하고 그 사실을 사진 아래에 표시합니다. 한 주 도중 사진이 임의로 바뀌지 않도록 선정 당시 기준을 유지합니다.
- 사진은 분위기를 위한 풍경이며 실제 청주시 현장 사진이나 실시간 날씨 화면은 아닙니다. 사진 아래에 적용 주간과 선정 당시 참고 기준을 표시합니다.
- 열린 작성 화면은 약 1분마다 주간 변경을 확인합니다. 주가 바뀌어도 작성 중인 본문·첨부·결재선은 유지합니다.
- 사진 조회 장애 때에는 기본 로컬 풍경을 표시하며 본문 입력을 막지 않습니다. 위로 문구·작성 전 확인·작성 흐름·글자 수 및 첨부 개수 표시를 유지합니다.
- 주간 사진 정보는 업무 자료와 별도 테이블에 저장합니다. 계정·카드·문서 정보를 사진 API에 포함하지 않습니다.

## 4. 업무점검 및 대사 — 항목별 업무진행절차

**YBY 승인 / 이관 기록 / 금액 미기재 / 미사용·0원 / 승인 취소 / 자기 결재**를 클릭하면 기존 실제 명세 목록 위에 각각 다음 내용을 표시합니다.

- 해당 집계에 포함되는 자료의 기준
- 준비할 원본 명세·증빙
- 조회 → 근거 대조 → 권한에 맞는 정정 → 재확인 → 점검 기록 보존의 6단계 절차
- 각 항목별 주의사항과 아래 목록으로 바로 이동하는 버튼

이관완료를 결재 승인완료로 간주하지 않으며 미기재와 0원을 구분합니다. 승인취소 원문은 보존하고 재승인된 새 건을 대조하도록 안내합니다. 자기 결재는 최종 상태와 독립 검토 근거를 확인하도록 안내합니다. 명세대조 기록은 승인완료인 점검 대상에서 작성하며, 대상이 아닌 기록은 원래 업무의 반납·정정 이력과 근거 문서로 보존하도록 구분했습니다.

안내 열람·목록 조회는 승인·반납·점검완료 처리가 아닙니다. 점검 입력값도 원래 업무 금액이나 결재 상태를 자동 변경하지 않습니다. 기존 작성자·최고관리자의 후속점검 권한을 유지합니다.

## 적용 및 자료 보존

1. 기존 서버의 DB·첨부·계정 복구 자료와 인증서·실행 설정을 전체 백업합니다.
2. 새 ZIP을 별도 폴더에 풀고 기존 `README_START_KO.md`의 실행·업데이트 안내에 따라 적용합니다. 기존 실행 폴더와 신규 설치를 구분하세요.
3. 신규 설치용 패키지에는 회사 운영 자료가 포함되지 않습니다. 서버 이전 시 기존 자료를 별도 복원해야 합니다.
4. 기존 DB 업데이트 전에 전체 백업을 만들고 저장 형식 버전 16을 기록합니다. 새 주간 사진 테이블을 추가하며 기존 업무 원문·계정·첨부를 일괄 재작성하지 않습니다.
5. 실제 최고관리자와 담당 지점 계정으로 필터·조회 건수·사진·점검 안내를 확인한 뒤 운영을 전환합니다. Windows 실기와 회사 운영 환경의 미검증 범위는 동봉 검증자료를 참고하세요.
