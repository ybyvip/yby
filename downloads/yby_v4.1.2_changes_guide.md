# V4.1.2 반납 정산·재보고 화면 개선

2026-10-17. V4.1.1을 기준으로 입력 화면과 이력 표시를 개선한 전체 패키지입니다.

## 달라진 화면

- 카드 반납의 사용함/미사용을 선택형 영역으로 정리했습니다. 사용함을 선택하면 정산 양식이 표시되고, 하단 버튼은 ‘반납 및 정산 신청’으로 안내합니다.
- 최초 반납 정산과 정정 작성·재보고는 같은 공통 양식을 사용합니다. 1. 정산 기본정보 → 2. 사용 및 금액 → 3. 건별 세부 정산 명세 → 4. 증빙 자료 순서가 같습니다.
- 건별 명세의 1000px 고정폭과 고정 입력칸 너비를 제거했습니다. PC에서는 항목을 두 줄로 정렬하고, 작은 화면에서는 세로로 재배치하여 작성창 안에서 입력할 수 있습니다.
- 수량 × 단가, 건별 금액, 총 정산 금액을 자동 계산합니다. 날짜 기본값을 바꿀 때 별도로 지정한 건별 날짜는 유지합니다.
- 재보고 화면에는 정정 요청 사유·이전 처리 메시지와 5. 재보고 메시지만 추가됩니다. 기존 증빙 유지, 새 증빙 추가, 건별 금액 수정이 가능합니다.
- 승인취소 이력 행 전체와 상태 배지, 상세 보고서의 취소 요약·처리 메시지에 옅은 주황색 음영을 적용했습니다. 상태 글자도 함께 표시합니다.
- 이력대장의 신청 일시·신청자와 결재/취소 일시·처리자를 옆에 배치했습니다. 사용일은 별도로 구분하고, 상세 보고서는 신청·결재 시각을 나란히 표시합니다. 승인취소 건은 원 승인 시각과 취소 시각을 각각 보여줍니다.
- 날짜와 시각은 시간대 정보가 있는 경우 한국 시간으로 표시합니다. 기존 시간대 없는 과거 기록은 저장된 표시값을 유지합니다.

## 회사 서버 적용

1. 사용 중인 V4.1.1의 ‘데이터 백업’에서 전체 백업을 내려받아 회사 내부에 보관하세요.
2. 직원의 입력을 잠시 중단하고 기존 서버 창에서 Ctrl+C로 정상 종료하세요. 창을 찾기 어려우면 새 패키지의 STOP_SERVER.bat를 사용하세요.
3. 이 ZIP을 기존 실행폴더 밖의 새 폴더에 전체 압축 해제하세요. `%LOCALAPPDATA%\YBY\app` 안에 압축을 풀지 마세요.
4. 기존 서버를 사용하던 동일 Windows 계정으로 새 폴더의 RUN_LAN_WINDOWS.bat를 실행하세요.
5. 실행 창의 READY V4.1.2와 로그인 화면의 V4.1.2를 확인하고 기존 회사 계정·비밀번호로 로그인하세요. 브라우저에 예전 화면이 남아 있으면 Ctrl+F5를 누르세요.
6. VERIFY_WINDOWS.bat로 실제 서버를 확인한 뒤 반납·정산·정정·재보고와 다른 PC 접속을 점검하세요.

실제 업무자료 위치는 `%LOCALAPPDATA%\YBY\app\data`입니다. 기존 DB·계정·비밀번호·첨부·인증서·LAN 설정을 유지합니다. 이 버전은 DB 스키마를 변경하지 않습니다. data 폴더를 새 시험자료로 덮어쓰지 마세요. 서버 재시작 후에는 다시 로그인해야 합니다.

동일 서버와 인증서를 유지하면 다른 PC는 기존 로그인 바로가기로 접속할 수 있습니다. 필요 시 OPEN_LAN_CLIENT.bat에서 새 LAN_CLIENT.zip을 전달하세요. 집에서 회사 서버에 접속하려면 기존과 같이 회사가 허용한 VPN/원격접속 설정이 필요합니다.

## 확인할 업무 흐름

- 반납 회수 → 사용함 → 건별 행 입력·추가 → 합계 확인 → 반납 및 정산 신청.
- 결재 승인 → 승인 취소·정정 및 사유 입력 → 정정 작성·재보고 → 같은 양식에서 수정 → 재보고 메시지 → 재결재.
- 이력대장: 승인취소 행의 음영, 신청/결재 일시, 원 승인/취소 시각, 기존 영수증을 확인하세요.
- 미사용 선택 시 정산 없이 반납만 처리되는지 확인하세요.

## 검증 범위

Linux/Python 3.12에서 API·권한·정산 자동검사와 실제 Chromium 화면 동작을 검사했습니다. PC부터 320px 폭까지 입력폼의 가로 넘침, 최초/재보고 입력구조 동일성, 두 건 정산·증빙·다중행 비고·취소·재보고·재승인·날짜 배치·취소 음영·인쇄 표시를 확인했습니다.

사용자 Windows/Edge/회사망에서 원격 실행한 결과는 아닙니다. 포함된 VERIFY_WINDOWS.bat 및 클라이언트 CHECK_CONNECTION.bat로 실제 환경을 확인하세요. 상세 결과는 VALIDATION_V4_1_2.md를 참조하세요.
