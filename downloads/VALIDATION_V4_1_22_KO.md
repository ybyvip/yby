# V4.1.22 실제 검증 결과

Linux / Python 3.12 / Node.js / 실제 Chromium·Playwright에서 임시 DB와 가상 업무자료로 검증했습니다. 기존 문서의 검증 주장을 복사한 결과가 아니라 이번 수정본에서 실행한 결과입니다.

## 통과

- 원본 V4.1.21 ZIP을 실제로 열어 파일 280개와 Python/HTML/JS 코드를 확인했습니다.
- 원본의 본사·서울·인천·정봉·임원실·광주 담당 계정으로 각각 로그인해 대여표 11열/9개 값 불일치를 재현했습니다. 수정본은 같은 6개 역할별로 서버의 지점 범위와 11개 값의 순서를 확인했습니다. 최고관리자의 전체 지점 트리도 확인했습니다. 실제 고객 계정이 아닌 각 지점/권한을 가진 시험 계정을 사용했습니다.
- `python -m unittest discover -s tests -v`: **376개 실행, 376개 통과**, 실패·건너뜀 없음. 기존 365개와 신규 11개입니다.
- 이후 추가한 스키마 9→10 자료 보존 및 불출예정 백업/복원 2개를 포함한 `python -m unittest discover -s tests -p test_v4122.py -v`: **13개 실행, 13개 통과**. 위 11개와 중복되는 11개를 제외하면 전체 검증은 서로 다른 378개입니다.
- 새 서버 검증: 임시저장·수정·삭제 때 카드/실제 이력 불변, 확정 원자성, 같은 요청 재전송 중복 방지, 두 동시 확정 중 하나만 성공, DB 쓰기 실패 때 전체 롤백, 다른 지점 및 무권한 차단, 사고 카드의 직접/임시저장 확정 차단, 첨부 접근 범위, 개별 점검 미완료→완료 이력 보존, 대상 위조 차단, 정정 원본/자동번호 보존, 업그레이드 때 계정 해시/업무/첨부 보존, 새 테이블 백업/복원.
- 기존 회귀 검증: 인증·권한, 지점 자료 격리, 세션, 결재/자기승인, 정정·취소·재보고, 외부 문서·엑셀이관·매칭, 하이패스, 백업·암호화·복원, 인증서/Windows 경로 관련 Python 검사.
- `node --test tests/ledger_v418.test.cjs tests/stats_v4115.test.cjs`: **2개 통과**.
- `python tests/browser_v4122.py`: 실제 화면의 6개 지역 역할, 최고관리자, 문서첨부 임시저장·수정·삭제·확정·미사용 반납, 사고 상태·계좌·한도, 연결 수기정정, 별도 열, 스크롤 고정 검색, 개별 점검 저장 성공/목록/상세/후속완료, 하이패스 현재/과거 행의 다른 배경, 넓어진 본문 확인. 1440/1024/768/390 폭에서 대장 문서 전체 가로 넘침 없음. JavaScript 런타임 오류 없음.
- `python tests/browser_v4121.py`: 기존 회사정책/지점 추가, 월별 점검/내보내기, 자기승인, 암호화 백업 다운로드, 틀린/올바른 암호 복원시험, 역할 격리 화면 통과.

- `python tests/browser_tls.py`: 별도 임시 NSS 저장소에 신뢰한 CA로 Chromium HTTPS 로그인, HTTP→HTTPS 전환, 로그아웃·창 재열기 후 로그인 통과. 인증서 검증을 끄지 않았습니다.
- `python tests/bootstrap_smoke.py`: 한글 경로의 읽기전용 원본 → 실행 폴더 설치, 실제 기동·로그인·업무 저장, 중복 기동 PID 유지, 원본 DB 보존과 반복 설치 자료 유지 확인.
- 전체 Python AST와 앱 JavaScript 구문 검사 통과.

장애 경로 테스트의 로그에는 의도적으로 주입한 DB 오류 등의 ERROR가 나타날 수 있지만, 해당 테스트는 롤백을 확인한 뒤 통과했습니다. 기본 명령 샌드박스에서 소켓 생성이 거부되어 실제 HTTP/브라우저 검사는 승인된 실행 방식으로 수행했습니다.

## 미검증·제한

- 실제 Windows에서 BAT/PowerShell/Edge 실행, Windows DPAPI와 파일 ACL의 실제 사용자별 작동.
- 고객의 실제 업무 DB·첨부·계정·운영 인증서를 이용한 현장 업그레이드와 사내 다른 PC 접속. 첨부에는 이 자료가 없으므로 가상 자료와 임시 인증서로만 검사했습니다.
- 모든 과거 버전의 브라우저 스크립트 전체, 전체 인쇄·엑셀 보고서의 모든 조합, 장시간 대규모 다중 사용자 부하. 이번 요청에 영향을 받는 흐름과 위에 적은 기존 화면 회귀만 실제 실행했습니다.
- 원본 이관 금액·출처·자동번호는 표시/보존 전용입니다. 금액을 수정하거나 실제 회계 마감/승인으로 변환하는 기능은 추가하지 않았습니다.

반영 전에는 기존 서버 종료·전체 백업 후 복사본으로 실제 업무자료를 확인하세요. 원래 인증서와 개인키를 새로 발급하거나 테스트 인증서로 덮어쓸 필요는 없습니다.
