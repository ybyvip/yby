# YBY V4.1.1 가정 개발·회사 적용 도구 검증

검증일: 2026-10-16. 프로그램 업무기능은 V4.1.1을 유지하고 분리 실행·배포·사전 백업 도구를 추가했습니다.

- Linux / Python 3.12에서 전체 자동 테스트 **165개 통과, 실패 0, 건너뜀 0**. 최종 실행 47.671초.
- 실제 HOME_START 실행: `127.0.0.1:5100` 수신, 개발폴더 data 사용, 외부에서 상속된 회사 DB·TLS 환경설정 제거 확인.
- 실제 Chromium: 로그인, 시험카드 저장, 로그아웃, 창 닫기, 새 창 로그인 통과. JavaScript 오류 없음.
- 중복 실행은 같은 PID를 재사용. HOME_LOGIN은 종료된 서버를 감지하고 시작 안내.
- 실제 빌드 도구가 임시 소스 복사본의 테스트를 실행하고 통과한 바이트로 회사용 ZIP 생성. ZIP CRC 및 MANIFEST SHA-256 검증.
- 회사용 ZIP에서 가정 DB·첨부·계정·비밀번호 저장값·인증서·LAN 설정 제외 확인.
- 실제 windows_bootstrap.prepare_runtime을 사용한 별도 시험폴더 업데이트에서 회사 DB·비밀번호 키·첨부·CA·개인키·LAN 설정의 바이트 동일성 확인.
- 업데이트 전 백업 ZIP의 모든 파일별 SHA-256 및 CRC 일치 확인. DB 무결성 검사 실패 시 백업/업데이트 중단 검증.
- 회사 서버 실행 중인 상황은 모의 입력으로 재현하여 백업/프로그램 교체를 시작하지 않음 확인.
- 백업 권한오류를 주입하여 프로그램 교체가 전혀 실행되지 않음 확인.
- 자동 테스트 실패를 주입하여 새 회사용 ZIP이 생성되지 않음 확인.
- 경로탈출·자료/인증서 경로 배포 차단, 새 코드 명시 등록, 링크 파일 배포 차단 검사 통과.
- 가정용 전체 ZIP: 162개 파일, 734630바이트. ZIP CRC 및 파일별 매니페스트 해시 일치. 업무 DB·실행 인증서·개인키 미포함.

## 실제 Windows에서 확인할 부분

사용자 집/회사 PC에 원격 설치하거나 실제 Windows·Edge·DPAPI·보안정책에서 실행한 것은 아닙니다. Windows의 네이티브 배치 실행, 사용자별 인증서 저장소, 백업 권한 및 실제 회사망 접속은 해당 PC에서 확인해야 합니다. 회사 적용 후 VERIFY_WINDOWS.bat와 다른 PC CHECK_CONNECTION.bat를 실행하고 수정된 업무 흐름을 수동 점검하세요. Windows 권한이 필요한 심볼릭 링크 생성 테스트 1개는 Windows에서 건너뜁니다. 빌드 결과에는 실행/통과/건너뜀 수가 별도로 기록됩니다.

자동검사는 모든 후속 수정의 정확성을 보증하지 않습니다. 각 수정 기능과 권한별 동작을 별도로 점검해야 합니다. 회사 적용 시 동일 Windows 사용자로 실행하고 기존 자료를 보호하세요. 되돌리기는 업데이트 직전 백업 시점으로 돌아가므로 업데이트 후 입력자료를 별도 보존해야 합니다.
