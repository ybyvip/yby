# YBY V4.1.7 메뉴·화면 디자인 개선

2026년 10월 19일 · V4.1.6 기준 전체 패키지

## 바뀐 부분

- 법인카드 관리 메뉴에서 ‘사용정산 이력대장’을 ‘사용 정산 및 결재’ 바로 아래로 옮겼습니다.
- 순서: 카드 현황 및 대여 → 불출 및 반납 관리 → 사용 정산 및 결재 → 사용정산 이력대장 → 불출/반납 이력 대장 → 법인카드 등록/수정/삭제.
- 일반 메뉴의 빨강·하늘색 별도 강조를 없애고 모든 항목의 글자색과 굵기를 통일했습니다. 선택한 메뉴는 차분한 청남색 배경과 흰 글자로 표시합니다.
- 본문 제목, 표 제목, 입력 라벨을 남색·회색 계열로 정리했습니다. 대시보드 요약 카드와 바로가기 버튼도 같은 계열을 사용합니다.
- 헤더의 계정·접속자 글자와 일반 작업 버튼을 정리했습니다.
- 승인·반려·대기·승인취소의 상태 표시, 취소 행의 음영, 오류·연체 경고, 삭제 버튼 등 의미가 있는 구분은 유지했습니다.

기존 로그인 사진·날씨·작은 로그인창 동작은 유지합니다. 이번 변경은 화면과 버전 표시 위주이며, 업무 처리·계정 권한·DB 구조·Oracle 연동 기능을 새로 변경하지 않습니다. Oracle 연동은 기존 정리자료와 담당자 회신을 바탕으로 후속 작업합니다.

## 기존 서버 PC에 적용하기

1. 현재 YBY에서 ‘전체 백업 만들기’를 실행하고 백업 파일을 안전한 곳에 보관합니다.
2. 접속 중인 사용자에게 저장·로그아웃을 안내합니다. 기존 서버 검은 실행창에서 **Ctrl+C**로 종료합니다. 로그인 브라우저만 닫으면 서버는 종료되지 않습니다.
3. 받은 `yby_v4.1.7_full.zip`을 **새 폴더에 전체 압축 해제**합니다. ZIP 안에서 바로 실행하지 마세요.
4. 기존 서버를 실행하던 **같은 Windows 계정**으로 새 폴더의 `RUN_LAN_WINDOWS.bat`을 실행합니다.
5. 실행창에서 **READY V4.1.7**, 업무 화면 상단에서 **V4.1.7**을 확인합니다. 서버 실행창은 유지하세요.
6. 메뉴 순서와 새 색상을 확인합니다. 이미 열려 있던 다른 PC 업무 화면은 로그아웃한 뒤 창을 닫고 ‘YBY 로그인’으로 다시 엽니다. 일반 브라우저에서는 새로고침하세요.

기존 실제 실행 폴더는 `%LOCALAPPDATA%\YBY\app`입니다. 새 패키지는 이 폴더의 프로그램 파일을 갱신하며 기존 DB·첨부·계정·인증서 설정은 보존합니다. 업무자료가 들어 있는 `data`와 `certificates` 폴더를 삭제하거나 새 배포 폴더의 내용으로 수동 덮어쓰지 마세요.

서버가 실행 중이면 기존 안전장치가 현재 서버에 재접속하므로 업데이트되지 않을 수 있습니다. 구버전이 보이면 서버 종료 여부를 먼저 확인합니다. `.lock` 파일을 수동 삭제하지 마세요.

## 다른 PC 및 새 설치

기존 사용 PC의 접속 주소·인증서는 바뀌지 않으므로 보통 클라이언트를 다시 설치할 필요가 없습니다. 새 PC는 서버의 `OPEN_LAN_CLIENT.bat`으로 위치를 열어 `LAN_CLIENT.zip`만 전달하고, 압축 해제 후 `INSTALL_AND_CONNECT.bat`을 실행하세요. 개인키가 있는 `certificates` 폴더나 업무 DB는 다른 PC로 전달하지 않습니다.

새 서버 PC 설치는 `README_START_KO.txt`와 `README_LAN_KO.md`를 따르세요. 기존 서버를 다른 PC로 이전하는 작업과 프로그램 업데이트는 다릅니다.

## 확인 범위

실행한 검사의 결과와 제한은 `VALIDATION_V4_1_7.md`에 기록합니다. 개발 환경은 Linux와 Chromium이며 실제 회사 Windows PC의 창 관리·방화벽·네트워크는 해당 PC에서 최종 확인해야 합니다.
