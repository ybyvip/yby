# YBY V4.1.19 업데이트 안내

## 이번 수정

### 업로드 완료와 재클릭

- 성공적으로 업로드한 행은 미리보기에서 제거합니다. 일부 행만 선택했으면 미처리 행만 남겨 이어서 업로드할 수 있습니다.
- 완료 뒤 같은 버튼을 다시 누르면 **‘이미 업로드가 완료된 자료입니다. 중복으로 반영하지 않습니다.’**라고 안내합니다.
- 같은 파일을 다시 검사해 모든 행이 중복인 경우에도 버튼으로 이미 반영됐다는 안내를 확인할 수 있습니다. 중복 이력을 새로 만들지 않습니다.
- 처리 중 표시와 실패 시 입력 보존은 유지합니다. 실패한 행을 성공한 것처럼 제거하지 않습니다.

### 작성기준일과 일련번호

- 두 대장에 **작성기준일**을 추가했습니다. 새 이력은 YBY에 등록될 때의 시각을 기록합니다. 과거 사용일·지급일·반납일과 별도입니다.
- 각 대장의 입력 순서에 따라 고정 일련번호를 부여하고, 기본 목록은 **일련번호 내림차순**으로 표시합니다. 과거 사용일의 자료를 나중에 입력해도 최신 번호로 위에 나옵니다.
- 정정해도 기존 행의 번호와 작성기준일은 바꾸지 않습니다. 누락된 반납 이력을 새로 추가하는 경우에는 그 반납 행에 새 번호가 생깁니다.
- 사용정산이력: **일련번호 → 입력경로 → 작성기준일 → 사용일**.
- 불출반납이력: **일련번호 → 이력ID → 입력경로 → 작성기준일**. 기존 이력ID는 유지합니다.
- 번호는 각 대장 전체 자료의 입력 순서를 기준으로 하므로, 지점·기간·업로드 건으로 좁혀 보면 번호 사이에 공백이 있을 수 있습니다. 필터를 바꿀 때 번호를 다시 매기지 않습니다.
- 기존 자료는 저장 순서를 번호로 보존합니다. 작성 시각은 기존 이관 시각·신청 시각·처리 시각 등 확인 가능한 기록을 사용하고 **‘기존 기록 기준’**으로 구분합니다. 기록이 없는 날짜는 **미기록**으로 남기며 업데이트 날짜로 채우지 않습니다.

### 모든 열의 필터

- 사용정산이력대장 15개 열, 불출반납이력대장 18개 열의 제목 아래에 각각 검색칸을 마련했습니다.
- 일련번호·입력경로·작성기준일·사용일·사용자·부서·금액·사용 여부·반납일·상태/관리 등 각 열을 검색할 수 있습니다. 여러 칸을 입력하면 조건을 함께 적용합니다.
- 일련번호와 숫자 이력ID는 `2`(정확한 번호), `1~5`(범위), `>=10` 등의 조건도 지원합니다. 다른 열은 입력한 문자열을 포함하는 값으로 검색합니다.
- 기존 상단 지점·사용일 범위 등 필터도 함께 사용할 수 있습니다. **조건 초기화**로 모든 열 조건과 업로드 한정 조회를 해제합니다.
- 엑셀/PDF 및 사용정산 조회 요약은 현재 필터 결과를 사용합니다.

### 업로드 건만 조회

- **엑셀 이력 반영 완료** 안내의 두 대장 보기 버튼은 **그 업로드 작업으로 입력한 엑셀 이력만** 보여줍니다. YBY 직접 입력이나 다른 업로드 건은 섞이지 않습니다.
- 화면에 **‘조회 범위: 이번 엑셀 업로드 건만 표시’**를 표시합니다. **전체 이력 보기**나 좌측 대장 메뉴를 누르면 전체 자료 조회로 돌아갑니다.
- 모든 엑셀 이관 자료를 한꺼번에 보려면 전체 조회에서 **입력경로** 열에 **엑셀 이관**을 입력하세요.
- 완료 안내의 숫자는 최초 업로드 당시의 결과입니다. 이후 수기 정정으로 반납 이력을 추가하면 현재 대장의 조회 건수는 달라질 수 있습니다.

### 엑셀 이관 자료 수기 정정

1. 사용정산이력 또는 불출반납이력 행에서 **수기 정정**을 누릅니다. 상세 보기에서도 열 수 있습니다.
2. **사용 여부(사용/미사용/미확인), 반납일, 부서, 반납·정산 진행상태**를 수정합니다.
3. **정정 사유**와 **현재 로그인 계정의 비밀번호**를 입력하고 **정정 저장**을 누릅니다.
4. 같은 이관 건에 연결된 두 대장의 기록이 함께 갱신됩니다. 카드 끝자리만으로 다른 행을 찾아 수정하지 않습니다.
5. 상세 보기에서 처리자·시각·사유와 **변경 전/변경 후**를 음영색이 다른 표로 확인합니다.

최고관리자는 모든 지점, 업무 권한이 있는 지점 담당자는 자기 지점 자료를 정정할 수 있습니다. 단순 조회 권한으로는 정정할 수 없습니다. 일반 YBY 결재 이력은 이 기능으로 바꾸지 않습니다.

- 원본 스냅샷·합계금액·사용일·일련번호·작성기준일·현재 운영 카드 상태·YBY 승인 기록은 보존합니다.
- 반납일을 처음 추가하면 해당 건에 반납 이력을 만듭니다. 반납일을 비우면 기존 반납 행을 삭제하지 않고 **반납기록 정정취소**로 보존합니다. 다시 반납일을 넣으면 같은 반납 행을 재사용하여 중복을 만들지 않습니다.
- ‘반납완료’ 상태에는 반납일이 필요하고, ‘반납대기’에는 반납일을 비워야 합니다. ‘미사용’ 상태는 사용 여부도 미사용이어야 합니다. 지급일보다 이른 반납일을 입력할 수 없습니다.
- 진행상태 수기 정정은 **YBY 승인완료를 생성하는 기능이 아닙니다**. 원본 금액은 유지하며, 미사용으로 정정한 이관 자료는 유효 사용금액과 통계에서 제외합니다.
- 다른 사용자의 선행 정정과 충돌하면 최신 자료를 확인하도록 안내합니다. 저장 실패 시 두 대장·원본 연결·정정 내역을 함께 취소합니다.

## 업데이트 방법

1. 기존 프로그램의 **전체백업**을 다운로드해 보관합니다.
2. 서버 창에서 **Ctrl+C**로 기존 서버를 종료합니다.
3. 새 ZIP을 새 폴더에 모두 압축 해제합니다.
4. 기존과 같은 Windows 계정에서 **RUN_LAN_WINDOWS.bat**를 실행합니다.
5. 기존 자료로 로그인하여 두 대장을 확인합니다. 일반 업데이트에는 백업 복구를 실행하지 않습니다.

기존 `%LOCALAPPDATA%\YBY\app\data`와 계정·첨부·인증서·사내망 설정을 유지합니다. 새 패키지에는 실제 회사 DB·Excel·암호·인증서 개인키를 넣지 않았습니다. 실제 회사 Windows/Edge/WebView2·방화벽 환경에서의 접속은 적용 후 확인해야 합니다.
