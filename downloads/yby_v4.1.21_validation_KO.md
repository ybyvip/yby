## 직접 확인하지 못한 범위

검사는 Linux Python3.12/Chromium에서 수행했습니다. 실제 회사 Windows/Edge/WebView2·CA/PFX 내보내기/가져오기·DPAPI 사용자 변경·방화벽/보안 정책과 Windows 암호화 설치 도우미는 직접 실행하지 못했습니다. PFX는 회사 정책에 따라 실패할 수 있으며 실패를 완료로 처리하지 않습니다. 새 회사 PC 복구·장기 혼합 부하·전원/장비 장애·8GiB 실파일 복원·제3자 침투/접근성 인증·SSO/MFA·이중화·실제 Oracle 접속도 완료 항목이 아닙니다.

암호화 지원 Windows 패키지 설치, 실제 회사 조직·명세 대사, 별도 보관 장치·암호 관리와 인수 체크리스트는 회사 담당자와 확인하세요. 전체 대응표는 REPORT_REMEDIATION_KO.md입니다.
