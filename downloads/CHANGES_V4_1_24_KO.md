## 알림·집계의 기준

- 최초 사용 때 기존 자료를 읽음 기준으로 등록합니다. 이후 변경부터 녹색 점으로 알려줍니다. 최근 업무 표에는 권한 내 최근 항목을 최대 100개 표시합니다. 초기 도입 시 과거 업무를 새 사건으로 오인하지 않도록 한 기준입니다.
- 로그인 중 약 5초 간격으로 새 소식을 확인합니다. 공지·불출예정·불출반납·정산결재·정산이력·카드 관리·하이패스·민원·보고서 자료의 추가/변경/삭제를 메뉴별로 감지합니다. 삭제는 원문을 되살려 표시하지 않으며 메뉴의 변경 표시로 알립니다.
- 메뉴를 확인한 화면의 자료 버전과 서버 버전이 다르면 읽음 처리를 거절해 새 알림이 사라지지 않도록 합니다. 표시 설정 연속 클릭도 마지막 선택을 순서대로 저장합니다.
- 모든 계정이 대시보드를 시작 화면으로 쓰되, 종합 집계는 기존 대시보드 권한을 유지합니다. 지점 범위 및 상세 조회 권한은 서버에서 검사합니다. 집계만 허용된 계정에는 카드 식별 상세를 보내지 않습니다.
- 사용내역 그래프는 보유 이력의 **누적 불출 횟수**, 특이사항 그래프는 **정상 이외 활성 카드 매수**입니다. 금액 사용통계나 모든 종류의 특이사항을 뜻하지 않습니다. 종료 카드 수는 현재 보유 수에 포함하지 않습니다.
- 하이패스 조회 권한과 등록·수정·삭제 권한을 별도로 적용합니다. 필요한 계정에 기존 등록·수정·삭제 권한을 부여하면 됩니다.

## 자료 보존 및 적용

스키마는 11→12로 갱신하며 새 `dashboard_users` 테이블에는 계정별 읽음 기준과 화면 표시 설정만 저장합니다. 공지 확인과 표시 설정은 원래 카드·불출·정산·결재 자료 및 업무 버전을 바꾸지 않습니다. 기존 계정·암호·카드 사고 이력·대체 연결·점검기록·첨부와 인증서 관련 기능을 유지합니다.

1. 운영 서버를 종료하고 DB·첨부·계정 관련 자료·인증서를 포함한 전체 백업을 보관합니다.
2. 이 ZIP을 새 폴더에 압축 해제하여 기존 실행 방식으로 시작합니다. Windows 실행 폴더 설치 시 기존 `%LOCALAPPDATA%\YBY\app\data`를 유지하고 프로그램 파일을 갱신합니다. 새 빈 DB로 기존 DB를 덮어쓰지 마세요.
3. 운영 자료의 복사본에서 로그인·자료 건수·사고 이력·첨부·권한·인증서 접속을 확인한 뒤 업무를 재개합니다.
4. 별도 서버로 이전할 경우 프로그램뿐 아니라 기존 DB·첨부·필요한 보안 자료도 함께 이전하고 서버 주소/접속 설정을 확인합니다. Windows 사용자나 서버가 달라질 때의 인증서·암호 보호 설정은 현장 확인이 필요합니다.
