## 미검증·적용 전 확인

- 실제 Windows BAT/PowerShell/Edge, 사용자별 DPAPI·ACL, 실제 회사 인증서의 현장 적용.
- 회사 운영 DB·첨부·계정으로 실제 업그레이드 및 별도 서버 이전, 사내 다른 PC의 접속.
- 장시간 대규모 부하·동시 알림 사용, 모든 과거 선택적 브라우저 검사와 모든 인쇄/엑셀 조합.
- 새 기록 기능 도입 전에 이미 삭제/덮어쓰기되어 보존되지 않은 과거 사건의 복구. 새 기능은 그런 자료를 만들거나 복원하지 않습니다.

서버 종료와 전체 백업 후 운영 자료 복사본에 먼저 적용하세요. 실제 Windows와 회사 자료에서의 확인을 이번 가상 자료 검증으로 대체하지 않습니다.
