# V4.1.24 실제 검증 결과

V4.1.23 전체 ZIP을 별도 폴더에 해제하여 수정했습니다. Linux/Python 3.12와 실제 Chromium/Playwright, 임시 DB·가상 자료·시험 계정으로 검사했습니다. 기존 운영 자료가 첨부되지 않았으므로 회사의 실자료로 검증했다고 주장하지 않습니다.

## 통과한 검사

- 전체 서버 회귀: `python -m unittest discover -s tests -v` **405개 통과**, 실패·건너뜀 없음. 기존 394개와 신규 11개입니다.
- 신규 API 검사: 비로그인 차단, 조회 권한 없는 자료의 제목/해시 비노출, 타 지점 격리, 최초 읽음 기준, 사용자별 알림 독립·재로그인 유지, 오래된 확인 요청 409/다른 메뉴 확인 403, 표시 설정 형식과 계정 격리, 알림 확인·설정 저장 후 업무자료와 업무 버전 불변, 집계 전용 계정에 카드 식별 상세 미제공, 종료 카드 제외, 정상 복구 이력 보존, 하이패스 조회 계정의 직접 수정 차단/허용 계정 수정 성공, 스키마 11→12 업그레이드 시 계정 암호 해시·이력·설정 보존, 만료 카드 사용가능 수 제외, 현재 카드가 없는 지점의 과거 불출 집계, 선택한 하이패스/유류대 유형만 XLSX 내보내기.
- `python tests/browser_v4124.py`: 요청 10항목을 실제 로그인·클릭·입력·재접속으로 검사. 반복 로그인 후 대시보드, 새 소식 표와 공지/민원/보고서 상세 연결, 붉은 숫자의 독립 목록, 정상 복구 후 사고 이력, 네 가지 상태의 다른 음영·현재 상태 문구, 사용가능 현황표, 하이패스/유류대 각각/둘 다/모두 해제, 조회 전용 계정의 수정 버튼 미표시·API 차단, 작은 관리 버튼, 권한 이름 한글, 네 계절의 내장 사진 실제 HTTP 응답, 녹색 점 생성과 메뉴 확인 후 해제, 표시 체크 설정 저장·재로그인 유지·전용 하위 메뉴, 지점별 그래프 3개와 타 지점 비노출, 1500/1024/768/390 폭의 대시보드 가로 넘침 없음, 사용정산 작업 버튼의 9~12px 글씨 및 넘침 없음. JavaScript 런타임 오류 없음.
- `python tests/browser_v4123.py`: 기존 사고 상세·대체카드·종료 연결, 임시저장→불출 확정→반납, 문서 첨부/미리보기/실제 다운로드, 수기정정·대장 열, 승인완료 건의 개별 점검·이력 보존·실제 XLSX 다운로드, 작은 화면의 불출 폼 통과. JavaScript 런타임 오류 없음.
- `python tests/browser_v4121.py`: 회사 정책·지점 추가, 월별 점검/집계·엑셀, 자기 승인 제어, 암호화 백업 다운로드·틀린/맞는 암호의 복원시험, 지점 계정의 관리자 화면 격리와 1440/1024/768/390 배치 통과.
- `python tests/browser_tls.py`: 인증서 검증을 끄지 않은 별도 신뢰 CA로 실제 Chromium HTTPS 로그인, HTTP→HTTPS 이동, 보안 쿠키, 로그아웃 후 재접속 통과.
- `python tests/bootstrap_smoke.py`: 읽기 전용 한글 경로 → 실행 폴더 설치, 실제 기동/로그인/업무 저장, 중복 기동 시 PID 유지, 원본 DB와 반복 설치 자료 보존 통과. Linux에서 Windows 설치 핵심 Python 경로를 검사했으며 실제 Windows BAT 실행을 뜻하지 않습니다.
- 전체 패키지의 MANIFEST SHA-256 일치, ZIP CRC, 운영 DB·개인키 미포함을 확인했습니다.
- Python AST 101개, 앱 JavaScript 구문 19개 및 기존 Node 대장/통계 검사 2개 통과.

자동 검사 중 롤백 확인을 위한 의도적 장애 주입 ERROR 로그는 테스트 실패와 구분했습니다. 권한이나 무결성 검사를 끄지 않았습니다. 화면 사진은 실제 가상 자료로 검사한 화면이며 운영 자료가 아닙니다.

## 현장 미검증

- 실제 Windows BAT/PowerShell/Edge 실행 및 Windows 사용자별 DPAPI·ACL·기존 사내 인증서의 현장 적용.
- 회사 운영 DB·첨부·계정으로 실제 업그레이드, 별도 서버 이전, 다른 PC의 사내망 접속.
- 장시간 대규모 부하·알림 지연, 모든 과거 선택적 브라우저 검사와 모든 인쇄/엑셀 조합.
- 계절 사진의 실제 모니터별 색감·조직의 디자인 선호. 네 계절의 파일 표시와 입력 가독성 구조는 확인했습니다.
