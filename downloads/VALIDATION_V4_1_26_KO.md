# V4.1.26 실제 검증 결과

V4.1.25 전체 ZIP을 별도 폴더에 해제한 코드에서 작업했습니다. Linux/Python 3.12, 실제 Chromium/Playwright, 임시 DB·시험 계정·가상 업무자료로 검증했습니다. 회사 운영 자료가 첨부되지 않아 실제 회사 DB·계정·사내 인증서로 검사했다고 주장하지 않습니다.

## 미검증·현장 적용 전 확인

- 실제 Windows BAT/PowerShell/Edge, Windows 사용자별 DPAPI·ACL 및 회사 인증서의 적용.
- 회사의 실제 운영 DB·첨부·계정으로 업데이트, 별도 서버 이전, 사내 다른 PC 접속.
- 장기간 대규모 동시 사용·모든 데이터 조합·모든 과거 선택적 검사·모든 인쇄/엑셀 조합.
- 운영체제/브라우저 자체 파일선택·인쇄 창의 이동 제어. 이번 드래그는 프로그램 내부 창에 적용했습니다.
- 사용자 이름 오기/동명이인에 대한 자동 동일인 판별. 집계는 동일 소속의 기록된 이름 기준입니다.
- 새 디자인의 모든 모니터·조직별 선호도. 적용한 주요 화면은 실제 브라우저와 여러 폭에서 확인했습니다.

전체 백업 후 운영 자료 복사본에 먼저 적용하세요. 점검 완료는 업무 원본 정정을 대신하지 않으며, 승인 금액/상태 변경은 기존 권한과 정정 절차로 처리해야 합니다.
