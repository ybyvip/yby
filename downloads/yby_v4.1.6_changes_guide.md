# YBY V4.1.6 사용·업데이트 안내

2026-10-17 · 작은 입력 패널 / 청주시 날씨 / 시간대와 움직임이 있는 해변 배경

## 요청하신 화면 개선

- 로그인 전용 창의 기존 **440×720 기준 크기**와 Windows 배율 대응을 유지했습니다. 로그아웃 후 작은 크기로 복귀하는 Windows 창 관리 코드는 V4.1.5와 동일합니다.
- 아이디·비밀번호 입력 영역을 아래쪽의 작은 패널로 줄였습니다. 440×690 웹 영역에서 패널 높이 330px 이하를 확인했으며, 배경 속 남녀가 전신으로 보이도록 사진 구도와 배치를 맞췄습니다.
- 새로운 낮·아침·노을·밤·비·눈 사진 6장과 기존 해변 사진을 포함했습니다. 배경은 프로그램에 들어 있어 인터넷 사진 사이트에 연결하지 않습니다.
- 사진이 천천히 이동·확대되고 사진 사이가 부드럽게 전환됩니다. 비·눈 예보에는 가벼운 날씨 효과도 있습니다. 실제 인물이 걷는 동영상은 아닙니다.
- ‘움직임 끄기/켜기’로 효과를 조절하고 선택을 해당 PC에 저장합니다. 처음에는 Windows의 동작 줄이기 설정을 따릅니다. 창을 숨기거나 업무에 로그인하면 배경 움직임과 주기적 날씨 조회를 멈춥니다.
- ‘다음 사진’은 다른 배경의 미리보기입니다. ‘자동으로’를 누르거나 5분이 지나면 시간·날씨에 맞춘 배경으로 돌아옵니다. 배경 변경 때문에 입력 중인 아이디·비밀번호를 지우지 않습니다.

## 청주시 날씨와 한국 시간

기준 지역은 사용자가 지정한 **대한민국 충청북도 청주시**입니다. 시계와 날짜·시간대는 접속 PC의 지역과 관계없이 한국 시간(Asia/Seoul)을 사용합니다.

기본 시간대는 05–09시 아침, 09–17시 낮, 17–19시 노을, 19–05시 밤입니다. 낮 시간의 비·눈 예보에는 해당 사진을 우선하며, 밤에는 야간 사진과 날씨 효과를 함께 사용합니다. 흐린 날은 채도를 낮춘 시간대 사진을 사용합니다. 실제 일출·일몰 시각을 계산하는 기능은 아닙니다.

날씨 제공자는 **MET Norway Locationforecast**입니다. 청주시 좌표(소수 둘째 자리)만 사용해 서버에서 공개 예보를 조회하며 API 키가 필요하지 않습니다. 표시되는 온도와 날씨는 예보 자료이며 실시간 관측값은 아닙니다. 출처: https://www.met.no/en/free-meteorological-data · CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ · 날씨 상태를 한국어로 요약하고 온도를 반올림해 표시합니다.

- 회사 서버에만 날씨 서비스 인터넷 연결이 필요합니다. 접속 PC는 회사 서버에서 사진과 날씨 요약을 받습니다.
- 제공자의 캐시 만료 시간을 반영해 여러 PC가 접속해도 조회를 공유하며, 실패 시 15분 동안 재시도 간격을 둡니다. 클라이언트는 로그인 화면에서 약 10분 간격으로 갱신합니다. 최초 조회 중에는 짧게 상태를 재확인합니다.
- 날씨 조회를 별도 작업으로 처리하므로 접속이 느리거나 끊겨도 로그인이 기다리지 않습니다. 신선한 예보를 받지 못하면 ‘날씨 연결 대기 · 시간대 배경’으로 표시하며 시간대 사진과 로그인은 계속 동작합니다.
- 외부 서비스로 업무자료·계정·비밀번호·로그인 쿠키를 보내지 않습니다. 위치 권한이나 PC GPS 정보를 요구하지 않습니다.
- 회사에서 외부 접속을 제한한다면 날씨 조회 대상은 `https://api.met.no/weatherapi/locationforecast/2.0/compact?lat=36.64&lon=127.49`입니다. 인증서 검증을 끄거나 방화벽 전체를 해제하지 마세요. 날씨 연결이 차단되어도 업무 프로그램을 사용할 수 있습니다.

## 서버 PC 업데이트

1. 기존 프로그램에서 전체 데이터를 백업합니다.
2. 열려 있는 YBY 로그인·업무 창을 모두 닫고 서버 실행 창에서 Ctrl+C로 종료합니다. 필요하면 STOP_SERVER.bat를 사용합니다.
3. 새 ZIP을 **새 폴더에 전체 압축 해제**합니다.
4. 기존 회사 서버를 사용하던 **동일한 Windows 사용자**로 새 폴더의 RUN_LAN_WINDOWS.bat를 일반 더블클릭합니다.
5. 서버 창에서 READY V4.1.6, 로그인 화면 하단에서 V4.1.6을 확인합니다. 이후에는 서버가 켜져 있을 때 시작 메뉴의 YBY 로그인을 사용합니다.

기존 서버가 실행 중이면 파일을 바꾸지 않고 그 서버에 연결합니다. 화면이 구버전이면 기존 서버와 YBY 창을 모두 종료한 후 다시 실행하세요.

실제 실행 폴더는 `%LOCALAPPDATA%\YBY\app`입니다. 기존 업무자료·계정·비밀번호·첨부·인증서·사내망 설정은 유지합니다. `data` 및 `certificates` 폴더를 삭제하거나 덮어쓰지 마세요. 서버 실행 창은 유지해야 다른 PC도 접속할 수 있습니다.

## 다른 PC

이미 V4.1.5의 로그인 전용 창을 사용하는 다른 PC는 서버 업데이트 후 YBY 창을 닫고 시작 메뉴의 YBY 로그인을 다시 열면 새 화면이 적용됩니다. 창 관리/접속 스크립트가 동일하므로 재설치는 필요하지 않습니다.

새 PC 또는 이전 접속 도구를 사용하는 PC는 서버에서 OPEN_LAN_CLIENT.bat → 새 LAN_CLIENT.zip 전달 → 새 폴더에 전체 압축 해제 → INSTALL_AND_CONNECT.bat 일반 실행 순서입니다. 이후 시작 메뉴의 YBY 로그인을 사용합니다. 기존 CA가 같으면 인증서 재발급은 필요하지 않습니다. 전체 서버 자료와 개인키는 전달하지 않습니다.

## 검증 범위

검사 결과는 VALIDATION_V4_1_6.md에 기록했습니다. 이 환경에서는 실제 Windows 창의 크기·배율과 회사 네트워크를 실측하지 못했습니다. 기존 Windows 창 관리는 그대로 유지했으며, 포함된 VERIFY_LOGIN_WINDOW_WINDOWS.bat와 VERIFY_WINDOWS.bat, 다른 PC CHECK_CONNECTION.bat를 사용할 수 있습니다.

개발 환경의 외부 네트워크 정책이 MET Norway 연결을 HTTP CONNECT 403으로 차단하여 **실제 청주시 예보 응답은 여기서 확인하지 못했습니다**. 정상·비·눈·만료·실패 응답을 사용한 캐시/API/화면 동작과, 실제 연결 차단 시 로그인·시간대 배경이 유지되는 동작은 확인했습니다.
