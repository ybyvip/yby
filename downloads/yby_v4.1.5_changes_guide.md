# YBY V4.1.5 적용 안내

2026-10-17 · V4.1.4 사용 환경에서 업데이트

## 변경 내용

- 시원한 청록색 바다와 해변에서 데이트하는 성인 남녀의 조감 사진을 로그인 배경으로 넣었습니다. 이 패키지를 위해 생성한 이미지이며 프로그램 안에 포함되어 외부 이미지 사이트에 연결하지 않습니다.
- 로그인 입력란은 밝은 반투명 패널로 구성했습니다. 작은 창에서도 아이디·비밀번호·로그인 버튼·버전 정보를 보기 쉽도록 간격을 정리했습니다.
- 로그인 전용 창은 440×720을 기준으로 일정하게 유지합니다. Windows 화면 배율을 반영하고 화면이 작으면 작업 표시줄을 제외한 영역 안에 맞춥니다. 로그인 상태에서는 크기 늘리기와 최대화를 제한하며 창 이동·최소화·닫기는 가능합니다.
- 로그인 성공 시 업무 창으로 넓어집니다. 업무 화면은 자유롭게 크기를 조절하거나 최대화할 수 있고, 로그아웃 시에는 최대화 상태를 복원한 뒤 작은 로그인 창으로 돌아옵니다.
- 웹페이지의 resizeTo가 브라우저에서 무시되던 부분을 Windows 전용 창 관리로 보완했습니다. 전용 프로필의 Edge/Chrome 프로세스와 정확한 YBY 창 제목을 확인하여 해당 창만 관리합니다. 일반 브라우저 창과 다른 프로그램 창은 크기를 조절하지 않습니다.
- 필요할 때 시작 메뉴의 ‘YBY 로그인’을 실행하는 방식입니다. Windows 부팅 자동 실행은 등록하지 않습니다.

## 서버 PC 적용 순서

1. 기존 프로그램에서 전체 데이터를 백업합니다.
2. 열려 있는 모든 YBY 로그인창과 업무창을 닫습니다. 서버 실행 창은 별도로 Ctrl+C로 종료합니다. 필요하면 기존 STOP_SERVER.bat를 사용합니다.
3. 새 ZIP을 **새 폴더에 전체 압축 해제**합니다. 이전 폴더 위에 일부 파일만 복사하지 마세요.
4. 회사 서버를 사용하던 **같은 Windows 사용자**로 새 폴더의 RUN_LAN_WINDOWS.bat를 일반 더블클릭합니다. 관리자 권한으로 실행하지 않습니다.
5. 서버 창에서 READY V4.1.5를 확인하고 로그인합니다. 처음의 작은 창 → 업무 화면에서 최대화 → 로그아웃 → 작은 로그인창 복귀를 확인합니다.
6. 다음 접속부터는 서버가 켜져 있는 상태에서 Windows 시작 메뉴의 **YBY 로그인**을 실행합니다. 서버 실행 창은 유지합니다.

기존 실행 서버가 남아 있으면 파일을 교체하지 않고 기존 서버로 연결합니다. 업데이트 후 버전이 4.1.4라면 기존 서버와 YBY 창을 모두 닫은 후 새 RUN_LAN_WINDOWS.bat로 다시 실행하세요.

실제 실행 폴더: `%LOCALAPPDATA%\YBY\app`

기존 업무자료·계정·비밀번호·첨부·인증서와 사내망 설정은 유지합니다. `data` 또는 `certificates` 폴더를 삭제하거나 집 PC의 자료로 덮어쓰지 마세요.

## 다른 PC 적용 순서

1. 서버에서 OPEN_LAN_CLIENT.bat를 실행하여 **이번 업데이트 후 생성된 LAN_CLIENT.zip**을 받습니다.
2. 다른 PC에서 기존 YBY 창을 모두 닫습니다.
3. 새 LAN_CLIENT.zip을 새 폴더에 **전체 압축 해제**한 뒤 INSTALL_AND_CONNECT.bat를 일반 더블클릭합니다.
4. 다음부터 시작 메뉴의 YBY 로그인을 실행합니다. 이번에는 `window_host.ps1`이 추가되므로 이전 설치 파일만 다시 실행하지 마세요.

현재 서버의 같은 CA가 이미 등록되어 있으면 인증서를 다시 만들거나 제거할 필요가 없습니다. 다른 PC에는 공개 접속 묶음만 전달하고 서버의 certificates 또는 data 폴더는 공유하지 마세요.

## 확인 결과와 확인 도구

이 개발 환경에서 수행한 항목: 자동 검사 164개, Chromium 로그인·로그아웃 반복 및 오류 처리, 작은 화면 배치, 로컬 배경 이미지 전달과 경로 접근 제한, 신뢰 CA를 사용한 HTTPS 로그인, PowerShell 구문 검사와 C# 창 관리 코드 컴파일, 이전 버전 자료를 유지하는 업데이트 검사. 구체적인 실행 결과는 배포 검증 보고서에 기록했습니다.

이 환경은 Linux이므로 Windows의 실제 HWND 크기 조절과 Windows 배율·다중 모니터·회사 보안 정책을 여기에서 실측하지는 못했습니다. 해당 부분은 다음 도구로 실제 PC에서 검사합니다.

- **VERIFY_LOGIN_WINDOW_WINDOWS.bat**: 서버나 업무자료에 접근하지 않고 임시 검사 창을 띄워 ‘최대화된 업무 화면 → 고정 로그인 크기’를 3회 검사합니다. PASS를 확인합니다. 다른 창이 움직이지 않는지와 프로필 구분도 검사합니다.
- **VERIFY_WINDOWS.bat**: 실제 서버 PC의 인증서·HTTPS·자료 잠금 등 기존 통합 검사입니다.
- 다른 PC의 **CHECK_CONNECTION.bat**: 해당 사용자 인증서와 실제 회사 서버 연결을 확인합니다.

새 로그인 창에 문제가 생기면 `%LOCALAPPDATA%\YBY\diagnostics\login_window_날짜_시간.txt`가 생성됩니다. 이 파일에는 비밀번호나 업무자료를 기록하지 않습니다.

브라우저 주소창으로 직접 여는 일반 웹 화면은 브라우저 크기를 따릅니다. 일정한 크기의 전용 로그인창은 새 시작 메뉴의 YBY 로그인 또는 새 접속 실행 파일로 열어 주세요.
